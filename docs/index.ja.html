Android のターミナル。そして Android を操る手。

root なしで Alpine / Ubuntu / Arch / Kali が動きます。タブの中に Linux のデスクトップ、あるいは VNC / RDP で他のマシンのデスクトップ。 そして、通知を出す・トーストを出す・あなたに質問する・電池やネットワークの変化で勝手に走る、 そんな 1 行のマクロが書けます。

できること

下にあるものは全部 APK 1 つに入っています。コンパニオンアプリも、セットアップスクリプトも、 先に繋ぎ込む準備もありません。

01ディストロがすぐ動く

APK を入れれば apk / apt / pacman が使えます。既定のエンジン z2root は本アプリ用に書いた ptrace ベースのユーザー空間実装で、root もカーネルモジュールも要りません。 Alpine / Ubuntu / Arch / Kali を設定から選べます。

02シェルが端末に手を伸ばす

約 20 個の z2-* コマンド。通知・トースト・クリップボード・センサー・ライト・音量・Intent・ アラーム・読み上げ・画面消灯の抑止・共有、そして自端末への無線 adb。 どれもただのコマンドなので、コマンドを呼べるものなら何からでも使えます。

03スクリプトがあなたに聞く

name=$(z2-ask "ブランチ名は？") と書くと、質問が通知シェードに出て、返信がそのまま シェル変数に入ります。アプリを開かずに答えられて、答えなければ非ゼロ終了 — 「やめる」も表現できます。

04アプリを閉じても続く自動化

z2-when が端末のイベントでスクリプトを起動します — 充電、電池残量、時刻や cron、Wi-Fi、 回線の切り替わり、起動、他アプリからの共有、受信 SMS、センサー、届いた通知、ファイルの追加。 ルールはただのテキストで、アプリを閉じたまま、再起動をまたいで動きます。

05タブの中の Linux デスクトップ

Xvnc + openbox を、アプリ内蔵の RFB クライアントで表示します。音声・動画つき。 z2gui でデスクトップを起動、z2run <app> で GUI アプリを起動して タブまで開きます。

06他のマシンのデスクトップも

同じビューアが リモートの VNC / RDP にも繋がります。保存した宛先に [VNC] と [RDP] のボタンが付き、RDP は NLA 認証・初回の証明書確認・マウスとキーボード・音・ テキストのクリップボード共有まで面倒を見ます。

07ファイルは 4 通りで

SSH / SFTP、FTP、WebDAV、SMB2/3 のクライアント。どれも既定では一時的な SSH ポート転送に乗るので、 資格情報が平文で流れません。鍵は Android Keystore が持つ ed25519、-L / -R の転送はタブを閉じても走り続けます。

08止まらないサーバー

起動コマンドを 設定 → 常駐サーバーに登録すると、アプリを開かなくても裏で動き続け、 再起動後も戻ってきます。小さな Web サーバー、同期デーモン、bot をスマホで常駐させられます。

09アプリを開かずに手の届く場所へ

マクロをクイック設定のタイルに置く（12 枠）、ステータスバーのアイコンを自分のドット絵にする、 ホーム画面のウィジェットからワンタップで走らせる。もう 1 つのウィジェットは ~ 配下の ファイルの末尾をホーム画面に出し続けます。

10USB 機器をふつうのプログラムから

z2-usb list して z2-usb allow、Android の許可を出せば、libusb や /dev/bus/usb/… を使うプログラムが手を入れずにその機器を開けます。 必要なのはデータの通る OTG アダプタかハブだけです。

11動かないとき

z2doctor が「なぜ動かないのか」に 1 コマンドで答えます。版数・エンジン・空き容量・ 必要な権限・検知と自動化の状態。NG の行には次の一手が付いていて、最後に Issue へ貼れる短い報告が出ます。

~ $ ls ~/.z2term/macros/

マクロはただのコマンド。だから発想しだいで何でもできる

覚える専用言語はありません。マクロは端末に触れるようになったシェルスクリプトです。 通知を出す、トーストを出す、あなたに聞く、ライトを点ける、自分をタイルに置く。書けることは全部できて、 しかも z2-when がそれをアプリを閉じたまま走らせます。右のスマホを見てください。

macros — z2term タブで切替
~ $ z2-notify -h -c "$(git rev-parse --short HEAD)" "ビルド完了" "3分12秒" # バナーで出て、「コピー」ボタンが付く ~ $ name=$(z2-ask "ブランチ名は？") ~ $ echo "$name" feature/rdp-audio ~ $ z2-when charge:start run ~/.z2term/macros/backup.sh w1756890000123 ~ $

一晩で組める、こんなこと

充電を挿したらバックアップz2-when charge:start run ~/.z2term/macros/backup.sh

寝ているあいだに終わっています。アプリは開きません。

通知に来た認証コードを拾うz2-when notify:otp run ~/.z2term/macros/otp.sh

手を伸ばす前にコードが抜き出され、クリップボードに入っています。

実行前に自分に確認させるz2-ask "本番に出す？"

スクリプトが通知シェードで待ちます。答えなければ止まります。

自宅の Wi-Fi のときだけ同期z2-when net:online if=ssid=Home cooldown=1h run ~/.z2term/macros/sync.sh

絞り込みはどのきっかけでも同じ書き方。飛ばした回もログに残ります。

他アプリから受け取って処理z2-when share:ext=pdf run ~/.z2term/macros/pdf.sh

共有シートで z2term を選ぶと、スクリプトがその PDF を片付けます。

毎日やることをタイルにz2-tile set 1 vpn.sh -l VPN

クイック設定からワンタップ。アプリは開きません。12 枠あります。

アイコンを自分で描くz2-icon set 1 ~/pixel/rocket.txt

ステータスバーの点が何を意味するのか、自分で決められます。

声で報告させるz2-say "ビルド終わった"

画面が消えていても、シェルスクリプトから読み上げます。

フォルダを見張るz2-when file:new=/sdcard/Download run ~/.z2term/macros/sort.sh

入ってきたファイルを、名前を変えるなり変換するなり送るなり。

ホーム画面から走らせるウィジェット → マクロを選ぶ

ワンタップで裏で実行。走っているものはもう一度タップで停止。

サーバーを立てっぱなしにz2-server start web

アプリを閉じても端末を再起動しても生きている Web サーバーや bot。

アプリ自身のタブを操るz2-session attach 2

別のタブに文字を打ち込むマクロ。ターミナルそのものの自動化です。

~ $ z2run xterm

タブの中のデスクトップ — 自分のも、よそのも

GUI タブは別のビューアアプリではありません。アプリの中の RFB クライアントなので、 Linux のデスクトップも、リモートのマシンも、シェルと同じタブの列に並びます。

localXvnc + openbox

z2gui でデスクトップが立ち上がり、z2run <app> は GUI アプリを起動して タブを開きます。音声と動画も橋渡しするので、プレイヤーはプレイヤーとして動きます。

vncRFB サーバーなら何でも

RFB 3.3 – 3.8、認証は None と VNC パスワード。宛先を保存すると、その横に [VNC] ボタンが付きます。

rdpWindows にもきちんと

NLA（ネットワークレベル認証）、初回の証明書確認、マウスとキーボード、音、テキストの クリップボード共有。保存した宛先に [RDP] ボタンが付きます。

ssh既定で SSH の中を通る

リモートデスクトップも FTP・SMB・WebDAV と同じく、既定では一時的な SSH ポート転送に乗ります。 直結にもできますが、そのときは「暗号化が無くなる」と警告してからです。

残りを 1 画面で

ターミナル
VT100 / xterm、256 色と true color、テーマ 9 種、検索つきスクロールバック、UTF-8 と東アジア文字幅、 代替画面、OSC 4 / 7 / 8 / 10 / 11 / 12 / 52。
エンジン
z2root — 本アプリのために書いた ptrace ベースのユーザー空間実装。root もカーネルモジュールも 不要。root 化済みの端末は chroot も選べます。
タブ
CUI と GUI のタブ、ドラッグで並べ替え。裏のタブは何か動いていると小さな点、 見ていないあいだに終わっていれば ✓ が付きます。
SSH
クライアントと、既定で localhost だけに bind する内蔵 sshd。アプリ内で作る ed25519 鍵、 Android Keystore で暗号化される秘密、known_hosts の確認、タブを閉じても生きるポート転送。
言語
英語・日本語・簡体字・繁体字。アプリの画面だけでなく z2-* のヘルプや使い方、 端末に出るメッセージまで切り替わります。
ロック
指紋・顔・画面ロック（PIN/パターン）で起動をふさぎ、離れているあいだは最近のアプリのサムネイルも 隠します。セッションと常駐サーバーは走り続けるので、夜通しの作業は壊れません。 z2scan self は外部ツールなしでこの端末を点検します（結果は端末内に留まります）。
通信量の上限
端末全体のモバイル通信量がその期間で設定値に達すると、z2term 自身の通信を止めます。 Wi-Fi と自宅 LAN はそのまま、他のアプリにも影響しません。
持ち出し
設定・接続先・スニペット・自動化ルール・マクロ・テーマ・タイル・アイコン・辞書・キーボードの学習を 1 ファイルにまとめて別の端末へ。定期実行もできます。SSH の秘密は既定で入れず、 入れるならパスフレーズが要り、そのときは中身ごと暗号化されます。
端末ログ
ツールバーの ⚪ を押すと、そのタブに出ているものが ~/z2term-log/ のテキストに書かれます。 もう一度押すと停止。既定では色と制御コードを落として素のテキストにします。
共有とスニペット
他アプリから共有されたテキストは入力行に挿入されるだけで、実行されません。 スニペットは棚に分けられるので、増えても使うものが沈みません。
ライセンス
GPL-3.0。テレメトリなし、アカウントなし、アプリ内課金なし、Google Play では配布していません。

入手する

APK は 1 つだけです。OS も外部の prebuilt も同梱していないので、初回起動で 設定 › Linux 環境からディストロを選びます。選んだものが公式 CDN から取得され SHA-256 で検証されます。 取得は 1 回きりで、更新のたびに落とし直したりはしません。

releases — github.com/orgsonai/z2term
~ $ ls -lh releases/latest/ -rw-r--r-- 1 you you 21M z2term-0.8.495-alpha.apk # 端末でタップ → 「提供元不明のアプリ」を許可 # 上書きインストールでデータは残ります

更新のしかた

アプリ内更新を確認

設定 → アプリ情報 → 更新を確認。ボタンを押したときだけ GitHub に問い合わせ、 新しい APK を落としてインストール画面まで連れて行きます。最後のタップは必ずあなたのものです （どのアプリも自分を黙って入れ替えることはできません）。端末からは z2-update。

自動Obtainium

Obtainium に github.com/orgsonai/z2term を登録すると、新しいリリースが出たときにワンタップで 更新できます。ストアは要りません。

手動APK をタップ

Releases から新しいファイルを落としてタップするだけ。上書きインストールになり、 データはそのまま残ります。

版数はまだ 0.8.x-alpha です。機能は広く、毎日使われていますが、 版数はそのことに正直にしています。
