# エッジパネルの部品と動作

対象: 0.8.617-alpha（versionCode 625）

追加の入口は「アプリ追加」と「項目追加」です。用途別のメモ・ターミナル・翻訳・マクロフォームの追加ボタンはありません。「項目追加」で部品と動作を選び、必要な項目を自分で組み合わせます。

| 部品 | 選べる動作 |
|---|---|
| ボタン | コマンド実行、状態付きボタン |
| 文字表示 | 実行結果を受け取る、固定値、コマンド出力の表示 |
| 入力欄 | 他の項目へ値を渡す、ファイルを読み書き、入力をコマンドへ送る、シェル接続 |
| 選択欄 | 選択した値を他の項目へ渡す |
| スイッチ | 状態の取得と変更 |
| リスト | 選択した値でコマンド実行 |

既存項目は削除・自動変換しません。従来のメモは「入力欄 → ファイルを読み書き」、簡易ターミナルは「入力欄 → シェルに接続」として編集できます。保存形式の `type=note` や `type=terminal` も引き続き使えます。

## 入力と結果の接続

「入力欄 → 他の項目に値を渡す」には初期値・必須指定・表示行数を設定できます。「選択欄」の選択肢は `|` 区切りです。固定値は「文字表示 → 固定の値を表示」で作ります。

ボタンではコマンドと、引数にする項目を必要な順番で選びます。画面の並び順と引数順は独立しています。「標準入力の参照元」に項目を指定すると、その値を標準入力にも渡せます。自由入力・選択・固定値に加え、ファイル入力、コマンド出力、前の実行結果も入力元にできます。

結果を別項目へ出すには「文字表示 → 実行結果を受け取る」を追加し、ボタンの「結果の表示先」で選びます。省略時は出力設定で、表示なし・項目の下・短いメッセージ・通知を選べます。旧 `type=macro` の省略時は従来どおりボタンの下です。

結果表示には停止・コピー・消去があります。同じ結果欄への同時実行は拒否します。入力値は実行時に取得するため、同じ結果欄を入力元と出力先にしても前の値を渡せます。関連付けは同じパネル内だけです。削除された入力元、入力元にできない部品、存在しない結果表示は実行前にエラーになります。

値に含まれる引用符・改行・空白・`$()` はシェルコードとして評価しません。引数はコマンドの末尾に渡すので、複合処理はスクリプトにまとめて呼び出してください。

```sh
z2-edge set PANEL:source type=argument label=入力 rows=3 order=10
z2-edge set PANEL:run type=run label=実行 run=cat stdin=source result=output order=20
z2-edge set PANEL:output type=result label=結果 rows=6 order=30
```

引数は最大16個・合計UTF-8 64KiB、標準入力と表示結果はそれぞれ64KiBです。通常の入力欄は16,384文字までです。実行時間は既定30秒、`timeout=1..300` で変更できます。出力は完了時に表示します。逐次出力・セッションが必要なら入力欄の動作をシェル接続にします。

## 項目ごとの大きさ・配置

各項目の「項目の大きさ・配置」で幅・高さを指定します。単位はdpまたは `%`。幅の割合は行・列、高さの割合はパネルが基準です。空欄は従来どおりの自動サイズです。高さを固定した項目は内容を内部スクロールできます。行内の先頭・中央・末尾寄せも指定できます。

パネルの「見た目 → 並べ方」は縦・横・グリッド・自由配置から選べます。自由配置では項目の `at=X%,Y%` を使い、0%が左端・上端、100%が右端・下端です。項目自体の寸法を考慮して端へ揃えます。座標なしの項目は順番に並べます。配置は数値入力で指定し、移動ドラッグは従来どおり順序の変更です。

```sh
z2-edge panel PANEL flow=free
z2-edge set PANEL:source width=50% height=160 'at=0%,0%'
z2-edge set PANEL:output width=50% height=240 'at=100%,100%'
```

## 保存と終了

入力・結果を接続したパネルは閉じるボタンで終了します。閉じる・タブ切替・再読込・画面消灯・設定への移動で接続したコマンドを停止し、一時的な入力と結果を破棄します。ファイル入力の本文は保存されます。入力元・出力先を接続していない通常の実行ボタンは従来どおりの寿命です。

パネル外側の長押しで設定を開けます。実行先は設定済みのローカル環境で、アプリ画面や通常のターミナルタブを開かずに利用できます。
