# エッジパネルのマクロフォームと翻訳

対象: 0.8.612-alpha（versionCode 620）

パネルの設定 → 項目 → **「＋ マクロフォーム」**で、引数欄・実行ボタン・結果欄をまとめて追加できます。実行ボタンを編集し、保存済みマクロを選ぶかスクリプトの呼び出しを入力してください。追加直後の汎用フォームには実行コマンドが設定されていません。

各部品は独立した項目です。並べ替えで配置し、引数欄と結果欄は表示行数（1〜20行）を設定できます。縦・横・グリッド配置を使えます。任意のXY座標へ置く方式ではありません。

## 引数と結果の関連付け

- **引数欄**: 自由入力・選択式・固定値。初期値、必須指定、表示行数を設定できます。選択肢は `|` 区切りです。
- **引数付きマクロ**: 引数欄を必要な順番で選択します。並び順が `$1`, `$2`, `$3` … になります。画面上の配置順には依存しません。結果欄も選択できます。結果欄を省略するとボタンの下に表示します。
- **結果欄**: 実行が受理されると前の結果を消去し、実行中・完了・エラーを表示します。「停止」「コピー」「消去」があります。「消去」は実行中の処理も停止します。同じ結果欄への同時実行は受け付けません。

GUIの引数選択は末尾に追加します。不要なIDや順番は引数欄IDの入力欄で編集できます。関連付けは同じパネル内だけで有効です。参照先を削除・別の型へ変更すると、実行前にエラーになります。

入力は文字列の引数として渡します。引用符、改行、空白、`$()` はシェルコードとして評価しません。設定する `run` は、引数を末尾に渡せるスクリプト・コマンドの呼び出しにしてください。複数の処理やパイプは別のスクリプトにまとめます。

```sh
z2-edge set PANEL:text type=argument label=文章 rows=3 required=on order=10
z2-edge set PANEL:language type=argument label=言語 argument-kind=choice 'choices=ja|en' default=ja order=20
z2-edge set PANEL:go type=macro label=実行 'run=sh "$HOME/example.sh"' args=text,language result=output order=30
z2-edge set PANEL:output type=result label=結果 rows=6 order=40
```

最大16引数、入力は1欄16,384文字、引数全体でUTF-8 64KiB、表示結果は64KiBです。実行時間は既定30秒、`timeout=1..300` で変更できます。完了時に標準出力を表示し、失敗時は標準エラーも案内します。対話式コマンド用ではありません。

フォームを含むパネルは外側タップや戻るでは閉じません。**閉じるボタン**で終了します。閉じる・タブ切替・再読込・画面消灯でフォームのコマンドを停止し、入力・結果を破棄します。開き直すと設定した初期値に戻ります。以前の実行結果が新しい画面を上書きすることはありません。通常の実行ボタン（`type=run`）の寿命は従来通りです。

エッジパネルを有効にしておけば、アプリの画面や通常のターミナルタブを開かずに使えます。実行先は設定済みのローカル環境です。

パネル外側のタッチはパネルが受け取ります。短いタップでは閉じず、長押しで設定を開きます。設定へ移ると実行中の処理は停止し、入力・結果は破棄されます。

## 翻訳フォーム

設定 → 項目 → **「＋ 翻訳フォーム」**で、文章・翻訳先・元言語・実行ボタン・結果欄を追加できます。元言語の `auto` は自動判定です。翻訳先の初期値は `ja`。言語候補は各引数欄の編集で変更でき、自由入力にも切り替えられます。

この操作ではアプリ独自のサンプル `~/.z2term/macros/translate.sh` だけを作成します。既存ファイルは上書きしません。**翻訳CLI・SDK・モデルは同梱せず、自動インストールもしません。** `trans` インターフェースの翻訳CLIは、ユーザー自身で使用するローカルLinux環境へ導入してください。未導入の場合は結果欄に準備の案内が出ます。接続先の利用条件が適用され、翻訳文は外部へ送信されます。通信・接続先の変更により利用できない場合があります。

ターミナルから使う場合は、APK更新後にローカルタブを開き、サンプルを導入します。

```sh
z2-macro install translate
sh ~/.z2term/macros/translate.sh "Hello" ja auto
sh ~/.z2term/macros/translate.sh "こんにちは" en ja
```

引数は **文章・翻訳先・元言語** の順です。先頭が `--help` 等の文章には `translate.sh -- "文章" ja auto` とします。文章をファイルやWebページとして扱わないため、`file://`・`http://`・`https://` で始まる入力は受け付けません。外部CLIの終了状態をそのまま返します。

翻訳も汎用フォームと通常のシェルマクロの組合せです。別用途のマクロへ差し替えて利用できます。既存の `type=input` は標準入力を送る従来の機能で、複数引数のフォームとは別です。
