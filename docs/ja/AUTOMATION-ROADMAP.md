# Android操作マクロの拡張方針

基本方針（2026-09-10）: 目標は、きっかけ・条件・複数の動作を組み合わせて作成・保存・再利用できる幅広いAndroid自動化です。設定の正本はコマンドとテキストです。GUIは編集・座標取得・確認を補助し、GUIでしか設定できる機能は作りません。シェルマクロと `z2-when` に接続し、バー・タイル・ジェスチャーは共通マクロの呼び出し口にします。

**メモ帳と操作マクロ（0.8.586）**: エッジパネルのメモ本文はダブルタップで編集を開始します。シングルタップではキーボードを開きません。コマンド一覧 → 自動化 → 操作自動化にマクロの一覧・作成・編集・複製・実行・停止・履歴を直接表示します。未保存の変更はタブ切替・閉じる・戻るで確認し、座標取得からは元のタブ内の編集へ戻ります。2026-09-12に利用者が実機動作を確認済み。

## 第1段の実装（0.8.571-alpha / 579）

**ビルド未検証・実機未確認**。名前付きテキスト定義の保存・取得・削除、`z2-action run/start/wait/status/stop/history`、座標指定のタップ・長押し・スワイプ、待機・アプリ起動・Android全体操作・シェル実行・時間指定のオートスクロールを追加しました。`z2-macro actions` からも同じ機能を呼べます。

実行は1本に限定し、完了待ち・取消・タイムアウト・通知停止・手順開始と終了の記録を共通化しています。保存時の画面寸法・向きと操作対象を確認し、実行中はパネルを一時非表示にします。[書式と使い方](ACTION-MACROS.md)を参照してください。

0.8.570までの取っ手ジェスチャー・動作列・可変速スクロールは引き続き使えます。今回の共通マクロはそれらからCLIを通して呼び出します。

## 第2段の実装（0.8.572-alpha / 580）

**操作マクロGUI（0.8.572）**: コマンド一覧 → 自動化 → 操作自動化から一覧・作成・手順編集・並べ替え・複製・実行・停止・履歴を開けます。タップ・長押し・スワイプは画面上で座標を取得し、pxまたは百分率へ戻せます。0.8.579から取得時のアプリ起動・対象指定は不要です。取得中のタッチは背後へ送らず、取消・画面変更・消灯・切断・2分経過で終了します。テキスト編集とCLIで同じ定義を使い、未保存の変更確認と保存競合の検出を備えます。アプリロックも引き継ぎます。ビルド未検証・実機未確認。

**座標だけの取得と設定画面の復元（0.8.579）**: 「座標を取得」はz2termの設定・編集タスクを保持したまま背景へ移し、座標選択を開始します。アプリ起動・対象指定の手順は不要です。「画面操作」で通常操作へ切り替え、目的の画面で取得を再開できます。取得時の対象窓チェックを外し、数値だけを下書きへ戻します。対象未指定でも保存でき、実行時に前面画面を解決します。対象窓の検査は維持します。設定画面の開閉・スクロール位置をバックグラウンド復帰とアプリロック解除後に復元し、マクロ編集のスクロール位置もロック画面で上書きしません。ビルド未検証・実機未確認。

## 第3段の実装（0.8.573-alpha / 581）

**操作マクロの反復・分岐・再利用（0.8.573）**: version=2 に回数指定／無限反復、端末状態や前面パッケージによる条件分岐、保存済みマクロの呼び出しを追加。呼び出し先を開始前に検査・固定し、循環を拒否します。親と子の制限時間、停止、全体10000命令の上限を共有します。GUIは反復／分岐の雛形と呼び出し先の一覧選択を備え、ブロックはテキストで編集します。実行位置・反復回数・分岐結果も表示します。詳細は[Android操作マクロ](ACTION-MACROS.md)。ビルド未検証・実機未確認。

## 第4段の実装（0.8.574-alpha / 582）

**UI要素とブロック編集（0.8.574）**: 表示文字・説明・要素IDによる押下／長押しと、期限付きの要素出現待ちを追加。対象アプリ上の一覧から指定を選び、CLIの inspect でも取得できます。入力欄・パスワード欄は対象外で、明示した要素操作・取得時だけ対象窓を読みます。反復・分岐はGUIで階層表示し、内部への追加、グループ間移動、複製・削除、不成立側の追加・削除に対応します。テキストとコメント・改行を保持し、停止・期限を共通管理します。[操作説明](ACTION-MACROS.md)を参照。ビルド未検証・実機未確認、追加テスト未実行。
