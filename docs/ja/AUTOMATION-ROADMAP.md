# Android操作マクロの拡張方針

基本方針（2026-09-10）: 目標は、きっかけ・条件・複数の動作を組み合わせて作成・保存・再利用できる幅広いAndroid自動化です。設定の正本はコマンドとテキストです。GUIは編集・座標取得・確認を補助し、GUIでしか設定できる機能は作りません。シェルマクロと `z2-when` に接続し、バー・タイル・ジェスチャーは共通マクロの呼び出し口にします。

## 第1段の実装（0.8.571-alpha / 579）

**ビルド未検証・実機未確認**。名前付きテキスト定義の保存・取得・削除、`z2-action run/start/wait/status/stop/history`、座標指定のタップ・長押し・スワイプ、待機・アプリ起動・Android全体操作・シェル実行・時間指定のオートスクロールを追加しました。`z2-macro actions` からも同じ機能を呼べます。

実行は1本に限定し、完了待ち・取消・タイムアウト・通知停止・手順開始と終了の記録を共通化しています。保存時の画面寸法・向きと操作対象を確認し、実行中はパネルを一時非表示にします。[書式と使い方](ACTION-MACROS.md)を参照してください。

0.8.570までの取っ手ジェスチャー・動作列・可変速スクロールは引き続き使えます。今回の共通マクロはそれらからCLIを通して呼び出します。

## 次の段階

| 優先 | 拡張 | 内容 |
|---|---|---|
| 1 | 座標取得と手順編集 | どの画面からでも点・経路を取得。数値入力、手順追加・並べ替え、待機編集。結果を同じテキストへ戻す |
| 2 | 反復・分岐・再利用 | 指定回数や無限反復、条件分岐、名前付きマクロの入れ子。停止・制限時間・履歴を維持 |
| 3 | UI要素指定 | 文字・説明・要素IDによる操作、要素出現待ち、回数制限付き再試行 |
| 調査 | 操作キャプチャー | 操作の記録と編集。全画面操作の録画や画像認識は個別に実現方法を検証 |

座標取得ではタップを背後へ通さず、取消手段と画面寸法・向きの記録を設けます。百分率座標だけではアプリのレイアウト変更を吸収できません。UI要素を読む段階では、現在のウィンドウ情報だけを使う機能との違いを明示します。
