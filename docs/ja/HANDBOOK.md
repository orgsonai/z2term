# Z2Term はじめてのハンドブック

これは Z2Term を**はじめて使う人**向けの、やさしい説明書です。
むずかしい技術の話は `docs/ja/DESIGN-SPEC.md` に分けてあります。
（English version: `docs/en/HANDBOOK.md`）

---

## 1. Z2Term ってなに？

**スマホ (Android) の中で Linux をそのまま動かせるターミナルアプリ**です。

- パソコンの「黒い画面 (ターミナル)」がスマホに入っていると思ってください。
- 中で **Alpine / Ubuntu / Arch / Kali** といった Linux が動きます。
- **root 化（端末の改造）は不要**。普通のアプリとしてインストールするだけ。
- `apt` や `pacman` でソフトを入れたり、`git`・`vim`・`python` などを使えます。

> できないこと: スマホの仕組み上、`ping` や一部のネットワーク低レベル機能は使えません
> （`nmap -sT` など別のやり方で代替できます）。

---

## 2. インストール

1. APK ファイル (`app-foss-debug.apk`) をスマホに入れる。
2. 「提供元不明のアプリ」を許可してインストール。
3. アプリを開く。

最初の起動で **Alpine Linux が自動でセットアップ**されます（少し待つと `#` のプロンプトが出ます）。
初回だけ、画面の上に**小さなカードが 3 枚**出ます。タップすると**入力欄にコマンドが入るだけ**なので、そのまま ⏎ を押すと動きます（通知を出す／ライトを点ける／PC からつなぐ）。3 枚とも触るか ✕ を押すと二度と出ません。もう一度見たいときは ⚙設定 › メンテナンス › 「はじめの案内をもう一度出す」。
これで準備完了です。

> ℹ️ `foss` 版（F-Droid / サイドロード向け）は Alpine 本体を APK に含めないため、**初回だけネット接続が必要**です（公式サイトから自動ダウンロードします）。`full` 版は同梱済みなのでオフラインでもすぐ起動します。

### 新しい版が出ているか確かめる

⚙設定 › アプリ情報 › **「更新を確認」** を押すと、GitHub の最新版と今の版を照らし合わせます。**押したときだけ**通信します（自動では確認しません）。新しい版があれば版数が出て、**「リリースページを開く」**でダウンロード先を開けます。APK を入れ直す手順はこれまでどおり手動です（上の「インストール」と同じ）。

## 3. 画面の見かた

```
┌───────────────────────────────────────────────┐
│ ホスト名 [モード]  📋 📜 🔅 🔒 🔍 ⌨ 🔴 ⚙     │ ← 上のバー (ツールバー)
├───────────────────────────────────────────────┤
│ [ archlinux ] [ + ] [ 🖥 ]                      │ ← タブ（複数の端末/GUIを切替）
├───────────────────────────────────────────────┤
│                                                │
│        ターミナル本体（文字が出る所）          │
│                                                │
├───────────────────────────────────────────────┤
│ ▾  (タップでキーボード開閉・指が 24dp 以上動くと無反応) │
├───────────────────────────────────────────────┤
│            キーボード                          │
└───────────────────────────────────────────────┘
```

**ツールバーのボタン (左から)**

| ボタン | はたらき |
|---|---|
| 📋 | クリップボードの文字を貼り付け（**ダブルタップでクリップボード履歴**を開いて選べる） |
| 📜 | コマンド一覧（よく使うコマンドをタップで入力）＋ **履歴**（過去に実行したコマンドを絞り込んで入力）＋ **SSH 接続 / SFTP** ＋ **サーバー**（常駐サーバーの管理）＋ **自動化**（`z2-when` ルールの一覧・**追加 / 編集**・ON/OFF・実行ログ・一時停止）（タブで切替） |
| 🔅 | 画面消灯ロック（ON にすると画面が自動で暗くならない。ON 中は 💡 に変わる）。**ダブルタップすると、このアプリの画面だけを暗くするスライダー**が出ます（暗い部屋用。ホームに戻れば元通り・「戻す」でいつでも解除）。**決めた明るさは覚えているので、次にアプリを開いたときも同じ暗さで出ます**（元に戻したいときは「戻す」） |
| 🔒 | バックグラウンド常駐（ON のあいだは画面を閉じても端末が動き続ける。ON 中は 🔒、OFF は 🔓）。**常駐サーバーを動かしている間は 🔒 が薄くなり切り替えられません**（サーバーがアプリを裏で生かし続けているので、ここで OFF にしても意味がないため）。この状態で 🔒 を押すと、**「セッションだけ終了」／「全部停止して終了」**を選ぶ画面が出ます（後述）。※ **外から ssh などで入れる状態を保つのは「常駐サーバー」の役目**で、🔒 だけでは保たれません（0.8.268。それまでは 🔒 も Wi-Fi をフルパワーに保っていましたが、電池を大きく消費するのでやめました）。⚠ ただし**常駐サーバーを動かしていても、Wi-Fi を繋ぎ直した直後は外から届かないことがあります**（端末が省電力で「自分の居場所」を答えなくなるため。Android 側の挙動で、アプリからは防げません）。**端末側から 1 回でも通信すると直る**ので、`ping -c 1 <ルーターのIP>` を打つか、`z2-when wifi:connect` に同じことを仕込んでおくと自動で戻ります |
| 🔍 | 画面の文字を検索（↑↓ で前後ジャンプ。**検索中は右のスクロールバーに見つかった場所の目盛りが出る**ので、どこに固まっているか分かります（目盛りをタップでそこへ移動）。入力欄は**タップした位置にカーソル**が移り、途中の打ち直しができます）。**内蔵キーボードのまま日本語で検索できます** — 変換中のかなは入力欄に下線付きで出て、確定すると検索語に入ります（0.8.275。それまでは確定するまで画面が変わらず、打てていないように見えていました）。OS のキーボードに切り替えているときは、これまでどおり OS の入力欄として動きます |
| ⌨ | スマホ標準のキーボード ⇄ アプリ内キーボード を切替。スマホ標準キーボードでも**変換中（確定前）の文字が端末のカーソル位置にインライン表示**されます |
| 🔴 / ⚪ | 端末ログの記録（押すと開始、もう一度押すと停止。**記録中は 🔴、停止中は ⚪**。**ダブルタップで詳細設定**） |
| ⚙ | 設定（**いつも一番右**。並べ替えでも動かず、消すこともできません） |

> **ボタンの並べ替え**: ツールバーのボタンを**長押し**すると、その場で**左右にドラッグして並べ替え**できます。長押し中はボタンの上に**はたらきの説明**が出ます。並びは記憶されます。

> **使わないボタンは消せます**: ⚙設定 →「表示」→「**ツールバー**」で、出すボタンをタップで選べます。明るく点いているものが表示中です。消したボタンの並び順は覚えているので、出し直せば元の場所に戻ります。
> 🔅 画面消灯ロックと 🔒 バックグラウンド常駐を消したときは、切り替える場所が無くなってしまうので、**同じ「ツールバー」の欄にスイッチが出ます**。

## 4. キーボードの使いかた

Z2Term には **アプリ専用のキーボード**が入っています。

### 英字キーボード
- 普通に文字キーをタップ。
- **⇧ (シフト)**: 1 回タップ=次の 1 文字だけ大文字 / もう 1 回=ずっと大文字 / もう 1 回=解除。
- **下フリック（キーを下にはらう）= 大文字**。例: `q` を下にはらうと `Q`。
- **上・左右フリック = 記号**（緑の小さい文字がヒント）。
- **長押しで連打**: 文字キー・数字・矢印・スペース・`⏎`（改行）は押しっぱなしで連続入力。`⌫`（消す）も長押しで連打。
- `CTRL` `ALT` を押してから文字 → Ctrl+C などのショートカット。`ALT` は**次に押すキーの前に ESC を付ける**修飾で、bash/zsh の行編集で使えます: `ALT`+`.` = 直前のコマンドの最後の引数を挿入 / `ALT`+`b`・`f` = 単語単位でカーソル移動 / `ALT`+`d` = 右の 1 単語を削除。`ALT`+矢印も同じく ESC 付きで送られます。⚠ 英語表示のときにあった `META` キーは `ALT` と全く同じ働きだったので、0.8.281 で**貼り付け / 絵文字のキーに変わりました**（下記）。Meta 修飾は `ALT` を使ってください。
- **貼り付けと絵文字（英語表示のとき・0.8.281）**: 📋 と描かれたキーを**タップすると貼り付け**、**上にはらうと絵文字**が出ます（キーの上に小さく 😀 が出ているのが目印）。場所は「4 方向フリック」なら `a` の左、「シンプル」なら左下です。出ている間はキーの面がパッドに変わり、**いちばん下の行（× ⌫ space ⏎ ← →）だけ残る**ので、貼った直後に消す・改行するがそのままできます。閉じるのは × か、開いたキーをもう一度押します。パッドの上の 😀 / 📋 タブで絵文字と貼り付けを行き来できます。
- **押すと背景が明るい緑に**変わります（どこを押したか見えやすく）。
- フリック中に指がしきい値を超えると、**飛ばし先の小さい文字（ヒント）が大きく強調表示**されるので、どこに飛ばすか確認してから指を離せます。

### 横画面のキーボード
- 設定の **「キーボード位置 (横画面)」** で **左 / 下 / 右** を選べます（縦画面では常に下）。
- **「サイドキーボード幅 (横画面)」** スライダーでサイド配置時の幅を、**「キーボード高さ (横画面)」** スライダーで全体の高さを調整できます。キーが大きい方が押しやすい・小さい方が画面を広く使えるトレードオフ。

### キーボードの「面」を切りかえる（0.8.305）

キーボードの**左下のキー**を押すと、キーの一式がまるごと入れかわります。これを**「面」**と呼びます。

| 面 | 中身 |
|---|---|
| **あ** | 日本語フリック（かな） |
| **A** | 英字（qwerty） |
| **12** | 数字だけ（テンキー） |

⚠ **キーに書いてあるのは「いま出ている面」ではなく「押すと行く先」**です。`12` と書いてあれば、押すと数字の面になります。

**数字の面（0.8.305）** は、ポート番号・IP アドレス・`chmod 755` のように**数字を続けて打つとき**のためのものです。英字の面にも上の段に数字が並んでいますが、横に 10 個あるので指が細かくなります。数字の面なら、かなキーと同じ大きさのキーで打てます。`.` `:` `-` `/` も一緒に置いてあるので、`192.168.10.20:2222` のような入力が面を移らずに終わります。

⚙設定 › **キーボードスタイル**のところで:

- **「数字の面を出す」** を切ると、**あ → A → あ** の 2 面だけに戻ります（見た目も前のバージョンとまったく同じです）。
- **「面の切りかえ順」** で **あ → A → 12** と **あ → 12 → A** を選べます。⚠ **選べるのはこの 2 つで全部**です。順ぐりに回るので、`A → 12 → あ` は 1 つ目とまったく同じ回り方になります。

### 日本語・かな漢字変換
- 左下のキーが **「あ」** のときに押すと、内蔵の**日本語フリックキーボード**に切り替わります。
- フリックのきまり: **タップ=あ / 左=い / 上=う / 右=え / 下=お**（よくあるスマホの 12 キーと同じ）。
- **カーソルキー ◀ ▶ ▼ ▲**: ◀ ▶ の**すぐ下**に、左に **▼（下）**・右に **▲（上）** があります（◀▶▼▲ は同じ大きさ）。何も入力していないときは端末のカーソルを動かします（コマンド履歴をたどる・行内を移動）。**日本語を入力している最中は ◀ ▶ が「入力中のカーソル移動」**になり、行頭まで動かせます。
- **「小゛゜」キー**: 直前の文字を `か→が→か`、`は→ば→ぱ→は`、`つ→づ→っ→つ` のように変えます。
- 入力中（未確定）は画面の上に**候補バー**が出て、漢字に変換できます。
  - **候補バーの左端には「打ったかな全体」**が出ます。カーソル（細いバー）より前が「先頭のかたまり（＝いま変換対象）」で濃く、残りは薄く表示されます。
  - **「変換」キー**で、先頭のかたまりを漢字に変換（連打で候補を順に切替）。候補をタップ／⏎ で確定すると、残りに進みます。
  - **長い文**を打った直後はカーソルが**末尾**（＝全体が変換対象）にあります。**◀ でカーソルを左に縮めると、そこまでが変換対象**になり候補が変わります（助詞や「です・ました」などはかなのまま残ります）。
  - 候補バーの**薄緑のかたまり**は「文まるごと」変換（例: 明日の天気はいかがでしょうか）。タップすると一文を一気に確定できます。◀ ▶ でカーソルを動かすと、その範囲に合わせて作り直されます。
  - **途中の打ち間違いを直せます**：◀ ▶ でカーソル（細いバー）を直したい場所へ動かすと、**そこにかなを差し込む・⌫ でその手前を消す**ができます（「小゛゜」もその位置の文字が対象）。カーソルは**行頭まで**動かせます。
  - **使った言葉から予測変換が出ます**：読みを打ちかけると、その読みで始まる「前に使った語句」が候補バーの先頭に出ます。たとえば「お」と打つと、過去に確定した「お願いします」「概ね」などが予測として並び、そのままタップで入力できます。予測を選ぶと、その語句は実際の読みで学習されるので、次回も同じ読みで予測に出続けます。
  - **かたまりの分け方も学習します**：たとえば「こまんど」が最初は「こ」「まんど」に分かれても、◀ ▶ で「こまんど」にまとめて確定すれば、次回以降は自動で 1 つのかたまり（コマンド）として認識されます。よく使う読みのかたまりほど優先されます。
  - **同じ読みの言葉がひととおり並びます**（0.8.297 / 0.8.298）：たとえば「とく」なら 得・特 のほかに **説く・解く・溶く**も候補に出ます（「きく」→ 聞く・効く・聴く、「みる」→ 見る・診る・観る）。それまでは辞書に持っているのに候補バーに一度も出てこない言葉があり、選びようがありませんでした。一度選べば学習して次から上に出ます。
  - **候補の数を増やしました**（0.8.298）：以前は候補が 16 個までで、⚠ **使い込んで学習が増えるほど、後ろに並ぶはずの言葉が押し出されて変換できなくなっていました**（「とく」で 説く が出ないのはこれでした）。上限を 48 個に広げ、さらに**打った読みそのものの変換は数の制限とは別枠**にして、学習がいくら増えても必ず出るようにしました。候補バーは**右にスクロール**できます。
  - **カタカナ**は候補バーのカタカナ候補をタップして選びます。
- 左下の**面の切りかえキー**で次の面へ移ります（`ABC` なら英字、`12` なら数字）。
- **⌫（消す）キーのフリック**: 左にはらうと**ひとつ前の単語をまとめて削除**、右にはらうと**入力中の行を全部削除**できます。⚠ **内蔵キーボードを OS の入力方法として使っているとき**も同じように効きます（0.8.312 で直しました）。それまでは 2 つのことが起きていました: **変換中（未確定のかなが出ている間）にはらうと、消えるはずのかなが確定されて入ってしまう**／**端末の画面では左右にはらっても何も起きない**。
- **絵文字を打つ（0.8.306 で場所が変わりました）**: **ESC キーを下にはらう**と、かなキーのところが**絵文字パッド**に変わります。上のタブでカテゴリを選び、スクロールして探してタップすると入力されます。⚠ **いちばん左のタブは「最近使った順」**なので、2 回目からはそこから選べます。左上の × で元のかなキーに戻ります。**顔と動物は Unicode の並びごと入っている**ので、「あるはずの絵文字が出てこない」ということがありません（0.8.301。それまでは手で選んだ表だったので 😌 など 13 字が抜けていました）。⚠ 0.8.305 まではスペースキーの上半分が 😀 キーでしたが、**一番よく打つスペースが半分の大きさ**になっていたので、スペースを元の大きさに戻し、絵文字は ESC のはらいへ移しました。
- **コピーしたものを貼り付ける（0.8.278）**: **ESC キーを上にはらう**と、同じ場所が**貼り付けパッド**に変わります。⚠ 上下にはらえることが分かるように、**ESC キーの上に小さく 📋、下に 😀 が出ています**（0.8.279 / 0.8.306。かなキーの角に出ているフリック先の文字と同じ意味です）。**ESC を押したままにする**と、キーの真上に「▲📋 ▼😀」が浮かぶので、そのまま上か下へはらってください。コピーしたテキストが新しい順に並ぶので、タップするとそのまま入力されます。✕ で 1 件消す、🗑 で全部消せます。⚠ **コピーしてからキーボードを開く**と履歴に入ります（Android の決まりで、キーボードは開いている間しかコピー内容を読めないためです）。パスワード管理アプリなどが「見せない」印を付けたものは履歴に残りません。
- ⚠ 絵文字パッド・貼り付けパッドを出している間も、**⌫ ⏎ ␣ ◀ ▶ はそのまま使えます**（貼った直後に消す・改行するがそのままできます）。絵文字と貼り付けはパッド上部の 😀 / 📋 タブで行き来できます。
- **パッドはキーボードを閉じると閉じます（0.8.307）**: 絵文字や貼り付けを出したままキーボードを閉じても、**次に開いたときはいつものかなキーから**始まります。⚠ それまでは開いたときの見た目がそのまま残っていて、開き直したのに絵文字パッドが出ている＝かなキーが見当たらない、という状態になっていました。かな・英字・数字の**面（文字盤）は今までどおり覚えています**。
- ※辞書ベースのかんたんな変換なので Gboard ほど賢くはありませんが、使った言葉は学習して上に出るようになります。

### スマホ標準のキーボードを使いたいとき
- ツールバーの **「あ」ボタン**をタップすると、いつものスマホのキーボード (Gboard など) に切り替わります。
- スマホ標準キーボードでも、**変換中（確定前）の文字が端末のカーソル位置にそのまま出ます**（インライン表示）。日本語変換や予測入力の途中経過が見えるので、確定してから初めて文字が現れる、ということがなくなりました。

## 5. よく使う操作

| やりたいこと | 方法 |
|---|---|
| 文字をコピー | 画面を**長押し**→指でなぞって範囲選択→「コピー」ボタン（行末の空白は自動で除かれ、行ごとに**改行**が入ります） |
| 選択中に拡大して見る | 選択中は指の上に**拡大鏡**が出ます |
| 画面の外まで選択 | 選択しながら**指を上端/下端**へ→自動でスクロールして続けて選べます |
| 貼り付け | ツールバーの **📋**。**改行を含む文字列のときだけ**「3 行 …」の帯が出るので、中身を見てから「貼る」を押せます（1 行ならこれまでどおりすぐ入ります）。**ダブルタップ**すると**クリップボード履歴**が開き、過去にコピーした文字を選んで貼り付けできます（貼り付けはシステムのクリップボードを書き換えません＝「貼り付けたのにコピーされる」ことはありません）。**履歴から選んだときも、改行を含むものは同じ確認の帯が出ます**（0.8.250） |
| 他のアプリでコピーした文字を使う | そのままこのアプリに戻れば、**戻った時点のコピー内容が履歴に取り込まれます**（📋 のダブルタップで選べます）。Android の制限で読めるのは**このアプリが前面のときだけ**なので、裏で動いている間のコピーは戻ったタイミングでまとめて 1 件だけ拾います |
| 上下にスクロール | 1 本指でドラッグ。**右端のスクロールバーを掴んで**動かすこともできます（触れた瞬間から動きます）。右下の **↓** で最新へ戻る |
| 文字を大きく/小さく | 2 本指で**ピンチ**（広げる/縮める） |
| 端末を増やす | タブの **+**（端末）/ **🖥**（GUI デスクトップ） |
| 端末を消す | そのタブを**ダブルタップ**（最後の 1 枚は消えません）。**そのタブで何か動作中のときは確認ダイアログ**が出ます（作業中の誤操作防止）。何も動いていなければそのまま消えます |
| タブの並べ替え | タブを**長押し**してから左右に**ドラッグ**（1 回の操作で端まで動かせます） |
| 動いているタブを知る | 見ていないタブで何か動いていると**タブ名の右に小さな点**が付きます。見ていない間に終わっていれば **`✓`**（そのタブを開くと消えます）。今開いているタブには付きません |
| タブの情報を見る | タブを**長押し**すると、タブ名と**実行エンジン**（PRoot / z2root / chroot / Android sh、GUI タブは GUI）がポップアップ表示されます（設定を開かずに確認できます。並べ替えと同じ長押しで併用） |
| アプリの版数を確認 | 端末で **`z2version`** と打つと、今動いているアプリの版数・実行エンジン・**実行中の OS（ディストロ）と kernel** などが出ます（`z2version --short` で版数だけ） |
| 過去のコマンド | **↑キー**（アプリを再起動しても履歴は残ります） |
| 端末の記録をとる | ツールバーの **⚪** を 1 回押すと記録開始（ボタンが点灯）、もう 1 回押すと停止。ファイルは `~/z2term-log/` にできるので、`less ~/z2term-log/<ファイル名>` でそのまま読めます。**ダブルタップ**で保存先・ファイル名・日時の書式などを変えられます |
| 他のアプリから文字やファイルを渡す | 相手のアプリで「**共有**」→ 一覧から **Z2Term** を選ぶ。文字はそのまま、ファイルは `~/z2term-inbox/` に取り込まれて**そのパス**が入力行に入ります。**入るだけで実行はされない**ので、続けて打ってから ⏎ してください |

> アプリを起動したときは**いつも端末タブが 1 つだけ**開きます（前回開いていた複数タブは自動では戻りません）。

> **端末ログ（⚪）について**
> - 記録は**タブごと**です。アプリを開き直すと必ず OFF に戻ります（うっかり記録し続けないため）。**「新しいタブは自動で記録する」を ON にすると**、開いたタブが最初から録られます（⚪ の押し忘れが無くなります。設定は覚えているので、次に開くタブから効きます）。
> - 出来上がるのは**普通のテキストファイル**です。色や画面制御の文字は取り除かれ、進捗表示（`50%→75%→100%` のように同じ行を書き換えるもの）は**最後の状態だけ**が 1 行として残ります。
> - **画面に出たものはそのまま入ります。** 表示された鍵・トークン・確認コードも記録されます（打つだけで画面に出ないパスワードは入りません）。記録中は必ずボタンが点灯するので、見れば分かります。要らなくなったログは普通のファイルなので `rm` で消せます。
> - **「各行の先頭に日時を付ける」**（既定 OFF）を ON にすると、`[2026-07-27 08:42:13] ` のように**桁の揃った日時**が各行の頭に付きます。いつ何が起きたかを後から追えます。⚠ **生ログのときは付きません**（バイト列をそのまま残すためです）。
> - **「鍵・トークンを伏せ字にする」は既定 ON** です。`TOKEN=…` のような「名前＝値」、貼り付けた秘密鍵の本文、`ghp_` / `AKIA` などの決まった形のトークンを `[z2term:masked]` に置き換えます。⚠ **完全ではありません。** 形がはっきりしているものだけが対象で、独自の形の秘密はそのまま残ります。**人に渡す前に必ず中身を見てください。**
> - 保存先の `~/z2term-log/` は**他のアプリからも見える場所**（ホームと同じ扱い）です。見られて困るものを置かない、という点はホーム配下の他のファイルと同じです。
> - 全画面で動くアプリ（画面を書き換えながら描くもの）の表示は、既定では記録しません。平たいテキストにしても読める内容にならないためです。

### よくあるつまずきの案内

`ping` が使えない・ポートが小さすぎる・`/sdcard` が見えない、といった**よくある詰まり方**をしたとき、画面の下に**次の一手が 1 行**出ます（数秒で消えます・タップでも消えます）。
端末に出た文字は**一切書き換えません**。別の場所に 1 行出しているだけです。
うるさいと感じたら ⚙設定 › 表示 › 「つまずきの言い換え」を OFF にしてください。

### 設定ごと持ち出す（機種変・入れ直しに備える）

⚙設定 › メンテナンス › **「持ち出し / 引き継ぎ」**で、いまの環境を 1 ファイルに書き出せます。

- 入るもの: **設定・SSH 接続先・スニペット・自動化ルール・マクロ**
- 入らないもの: **OS 本体**（数百 MB。入れ直せば戻るので含めません）・ログ
- **SSH のパスワードと鍵は既定では入りません**。入れたいときはチェックを付けると**合言葉**を聞かれます（合言葉が無いと戻せないので、忘れないものにしてください）。
- 戻すときは、**何が何件入るか**を見てから決められます。いま入っているものは消えず、同じものだけ置き換わります。

### SSH の鍵をアプリで作る

📜 →「SSH / SFTP」で接続先を作り、認証を「公開鍵」にすると **「鍵を作る（ed25519）」**が出ます。
押すと鍵ができて、**公開鍵をコピー / 共有 / この端末の sshd に登録**がその場でできます。
接続先のサーバーには、この**公開鍵**を登録してもらってください（秘密鍵はこの端末から出ません）。
自分で用意した秘密鍵を貼る欄はこれまでどおり残っています。

### 過去に打ったコマンドをもう一度使う（履歴）

ツールバーの **📜 →「履歴」タブ**に、端末で実行したコマンドが**新しい順**に並びます。

- 上の欄に文字を入れると絞り込めます。**空白で区切ると「全部を含む」もの**だけが残ります
  （`git log` と打つと `git --no-pager log` も出ます）。
- コマンドをタップすると**入力行に入るだけ**で、実行はされません。続けて直してから ⏎ してください。
- 中身はシェルの履歴ファイル（`~/.bash_history` と `~/.zsh_history`）そのものなので、
  端末で `history` して見えるものと同じです。アプリが別に記録しているわけではありません。

## 6.5. `claude`（Claude Code）を動かす

FOSS ビルドは中身を ptrace で包む独自エンジン（z2root）で動きます。`claude` の配布物には
**musl 版**と**glibc 版**があり、musl 版は z2root 上で起動できません（musl の ld.so は
非PIE 実行形式を起動できないため）。なので **glibc 版**を入れて使います。

**必ず glibc 系ディストロ（Arch など）のタブで**次を実行します（Alpine など musl のみの
ディストロでは入りません）。

```sh
# 既存の(musl かもしれない)バイナリを消して、入れ直し時に種類を再判定させる
rm -f ~/.claude/downloads/claude

# 公式インストーラ（Arch では自動で glibc 版を選ぶ）
curl -fsSL https://claude.ai/install.sh -o /tmp/ci.sh && bash /tmp/ci.sh

# パスを通す（入れた場所は ~/.local/bin）
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc

# 自動更新で musl 版に差し替わらないよう固定
echo 'export DISABLE_AUTOUPDATER=1' >> ~/.bashrc
```

タブを開き直す（または `source ~/.bashrc`）と、あとは `claude` だけで起動します。

> ポイント
> - この導入は **タブ（ディストロ）ごとに初回 1 回**だけです。2 回目以降は `claude` だけで OK。
> - 既に新しい版が入っているとインストーラはダウンロードを**飛ばす**ので、種類を入れ替えたい
>   ときは上の `rm -f` を先に実行してください。
> - 入れた中身は `~/.local/share/claude/versions/<版数>` に、`~/.local/bin/claude` はそこへの
>   ショートカット（symlink）です。

## 7. パソコンから Z2Term につなぐ（SSH サーバ）

スマホを SSH サーバにして、PC から入れます。

1. 端末で `passwd` を実行して **root のパスワードを設定**（初回のみ）。
2. 端末で **`sshd`** と入力。→ SSH サーバ (dropbear) が起動します。
   - 設定 (⚙) →「sshd 起動」ボタンでも同じことができます。
3. 表示された IP に PC からつなぐ:
   ```
   ssh -p 2222 root@<スマホのIP>
   ```

**ポートを変えたいとき**
- `/etc/ssh/sshd_config` の `Port` を書き換えると、`sshd` はそのポートで起動します。
- 一時的に変えるなら `sshd -p 50000` のように指定もできます。
- ※ポート番号は **1024 以上**にしてください（それ未満はスマホの制約で使えません）。

**つけっぱなしにしたいとき**
- ⚙設定 →「常駐サーバー」に `sshd`（LAN に公開するなら `sshd --lan`）を登録すると、アプリを開かなくても動き続けます。
- 常駐サーバーとして起動したときは、`-D` を付けなくても**自動でつけっぱなしの形（前景）で動きます**（0.8.165。それ以前は数秒ごとに再起動がかかり、接続が弾かれる・すぐ切れることがありました）。

> 補足: `/usr/sbin/sshd`（OpenSSH）はこのアプリの仕組みでは動きません。**必ず `sshd`** と打ってください
> （中身は軽量な dropbear が動きます）。

---

### トンネルを常駐させる（外から入る・遠くを持ってくる）

📜 →「SSH / SFTP」で接続先を編集すると、**ポート転送**を追加できます。向きが 2 つあります。

| 向き | 何が起きるか | 例 |
|---|---|---|
| **-L** | **遠くのサービスをこちらへ**持ってくる | 自宅 PC の Web を、スマホの `127.0.0.1:8080` で見る |
| **-R** | **こちらを遠くから**触れるようにする | 自宅サーバー側から、外出中のスマホへ ssh で入る |

転送を 1 つ以上作ると「**このトンネルを常駐させる**」が出ます。ON にすると
**SSH タブを閉じても転送が生き続けます**（常駐サーバーと同じ扱いで、端末を再起動しても戻ります）。

- **`-R` は常駐と組み合わせて初めて意味を持ちます**。入りたい時にスマホ側でタブを開いている
  必要があるなら、そもそも外から入る必要がないからです。
- **先に SSH タブで 1 度接続して、ホスト鍵を承認しておいてください。** 常駐中は確認画面を
  出せないので、知らないホストへは**繋ぎません**（黙って信用しない作りです）。
- 回線が切れたら**5 秒→10 秒→…→最大 5 分**の間隔で自動的に繋ぎ直します。
- ⚠ `-R` を使うと、接続先から**この端末に入れる状態**になります。必要なときだけ ON にしてください。

## 7.5. PC なしで `adb` を使う（`z2adb`）

このスマホ自身に `adb` でつなげます（PC も USB も不要）。`z2adb` がそのお手伝いをします。

1. **ワイヤレスデバッグを ON**: 設定 → 開発者向けオプション → 「ワイヤレスデバッグ」を ON（Android 11 以上）。
   - 開発者向けオプションが無いときは「設定 → 端末情報 → ビルド番号」を 7 回タップで出ます。
2. 端末で **`z2adb setup`** → `adb` 本体を入れます（ディストロに合わせて自動で導入）。
3. 「ワイヤレスデバッグ」の中の **「ペアリングコードによるデバイスのペア設定」** を開き、出てくる
   **ポート番号**と **6 桁コード**を使って:
   ```
   z2adb pair <ポート> <6桁コード>
   ```
4. 「ワイヤレスデバッグ」画面の直下に出ている**接続用ポート**で:
   ```
   z2adb connect <ポート>
   ```
   初回は画面に「このデバイスを許可しますか？」と出るので **許可**します。
5. つながったら、あとは普通の `adb` です:
   ```
   z2adb shell        # 自分のスマホのシェルに入る
   z2adb logcat       # ログを見る
   z2adb status       # つながっている端末を確認 (adb devices -l)
   ```

> ヒント: ポート番号は毎回変わります。`z2adb pair` / `z2adb connect` を**番号だけ**で打つと、その場で
> ポートを聞かれます。`z2adb` の語を付けずに `adb …` と同じ書き方をしても、`z2adb` は中身を `adb` に
> そのまま渡します（`z2adb shell` ≒ `adb shell`）。

## 9. 設定（⚙）でできること

⚙ を押すと**設定ページ（全画面）**が開きます。左上の **←** かスマホの戻るボタンで前の画面に戻れます。

設定は **7 つのグループ**（表示 / キーボード・入力 / Linux 環境 / 常駐サーバー・自動化 / メンテナンス / 開発者向け / このアプリについて）に分かれていて、**見出しをタップで開閉**できます。開閉した状態は**アプリを閉じても覚えています**ので、よく使うグループは開いたままにしておけます。

| 設定 | 説明 |
|---|---|
| テーマ | 配色（9 種類） |
| フォント | 表示する書体（4 種類、プレビューあり） |
| 文字サイズ | 4〜32（ピンチでも変えられます） |
| スクロールバック行数 | さかのぼれる行数 |
| ツールバー | **端末の上に出すボタンを選ぶ**。実物のボタンが並ぶので、タップで消す／戻す。消しても並び順は覚えています。⚙ は常に右端で消せません。🔅 画面消灯ロックと 🔒 常駐を消したときは、切り替えるスイッチがこの欄に出ます |
| ディストロ | Alpine / Ubuntu / Arch / Kali |
| ログインシェル | zsh / bash / sh — **端末タブだけでなく SSH ログイン・GUI 内ターミナルにも同じシェルが使われます**（その OS の `/etc/passwd` のログインシェルも書き換わります）。選んだシェルがその OS に入っていないときは、これまでどおり既定のシェルで起動します |
| キーボードスタイル | シンプル / 4 方向フリック |
| 数字の面を出す | 内蔵キーボードに**数字だけの面**（テンキー）を足します（0.8.305）。切りかえキーの行き先に `12` が挟まります。切ると **あ → A → あ** の従来どおりに戻ります |
| 面の切りかえ順 | **あ → A → 12** / **あ → 12 → A** の 2 択（0.8.305）。⚠ 選べるのはこの 2 つで全部です（順ぐりに回るので `A → 12 → あ` は 1 つ目と同じ回り方）。**数字の面が ON で、表示言語が日本語のときだけ**出ます — 面が 2 つしかないと「切りかえ順」という考えが成り立たないためです |
| 補助キーバー（OS のキーボード使用時） | スマホ標準のキーボードに切り替えているとき、その上に出る **ESC・TAB・CTRL・矢印などの補助キー**を出すかどうか（0.8.279）。OFF にすると出ません。内蔵キーボードのときは元から出ないので影響しません |
| 日本語 IME 学習履歴 | 変換で覚えた語句の一覧。検索して 1 件ずつ消す・全部消すができます |

### 常駐サーバー（アプリを開かず動かす）

⚙設定 →「**常駐サーバー**」→「サーバーを管理」、またはツールバーの **📜 →「サーバー」タブ**から、好きなサーバーを常駐させられます（どちらも同じ画面です）。

1. 「**+ 新規**」でサーバーを追加。プリセット（SSH / HTTP / SMB / FTP / VNC）を選ぶと起動コマンドが埋まります（中身は自由に編集可）。
2. サーバー本体（`sshd` / `smbd` など）は、あらかじめ端末でそのOSに導入しておいてください（アプリには同梱していません）。
3. 「**起動**」で今すぐ全サーバーを立ち上げ。各行に稼働状態（`running` 等）が出ます。落ちても**自動で再起動**します。
4. 各サーバー行の**トグル**で、常駐中でも**その 1 本だけを単独で起動/停止**できます（他のサーバーは止まりません。切替は約 1 秒で反映）。停止中に切り替えた場合は設定として保存され、次の「起動」時に反映されます。
   - **常駐したままサーバーを追加・編集・削除できます**（数秒で反映されます）。以前は追加したものを動かすのに全部を再起動する必要があり、そのとき他のサーバーも巻き添えで止まっていました。
   - 各行の **▤ ボタン**で、そのサーバーが出したメッセージ（ログ）を見られます。うまく動かないときはここに理由が出ています。「ログを消す」でいつでも空にできます。
   - 落ちて再起動が繰り返されているときは、行に「**再起動 N 回 / 前回の終了コード**」が出ます。数が増え続けるなら起動に失敗し続けているので、▤ でログを見てください。
   - 各行の **≡ を掴んで上下にドラッグ**すると**並べ替え**できます（スニペットと同じ操作）。並びは記憶されます。動いているサーバーは並べ替えても止まりません。
5. 「**起動時に自動で常駐**」を ON にすると、**次回から端末を起動しただけで（アプリを開かなくても）自動で常駐**します。
6. 止めたいときは通知の「**サーバー停止**」ボタン、またはこの画面の「**停止**」で一括停止できます。

※ 1024 未満のポート（80 など）は root 無しでは開けません。高いポート（8080 等）を使ってください。
※ 電池最適化から除外しておくと、バックグラウンドで止められにくくなります（⚙設定内の案内から）。
※ 電池が気になるときは「**省電力モード**」を ON に。⚠ **場所は ⚙設定 → 自動化 → バックグラウンドのプロセス保護 です**（0.8.309 で 📜 サーバータブから移しました）。画面消灯中に端末を深く眠らせて電池を節約しますが、その間は外部からの着信が遅延・取りこぼすことがあります（到達性より電池優先）。**0.8.269 から、ツールバーの 🔒 バックグラウンド常駐にも同じ設定が効きます**（それまでは常駐サーバーを省電力にしても 🔒 の側が端末を起こし続けていました）。⚠ **自動化（`z2-when`）の反応の速さもこの設定で変わります** — 自動化は自分では端末を起こさず、常駐サーバーか 🔒 が起こしている状態に相乗りして動くためです。⚠ 逆に、常駐サーバーも 🔒 も動いていないときは、この設定をどちらにしても何も変わりません。

※ **0.8.268 で、常駐しているだけで電池が減る問題を直しました**。それまではサーバーの様子を 1 秒ごとに見に行っており、そのたびに端末の中で小さなプロセスがいくつも起きていました（動いていないサーバーの分も）。これが積み重なって本体が常に温かくなる原因になっていたので、**見に行く間隔を 5 秒に広げ**、常駐通知も**稼働数が変わったときだけ**書き換えるようにしました。代わりに、サーバーの ON/OFF や追加・編集・削除の反映が**最大 5 秒**遅れます。

#### 常駐サーバーを動かしている間に端末を消したいとき

常駐サーバーが動いていると、アプリはずっとバックグラウンドに残ります。そのため**最近履歴（タスク一覧）からスワイプで消しても端末は消えません**。この間、ツールバーの **🔒 は薄くなり切り替えられなく**なります（OFF にしても意味がないため）。

薄くなった **🔒 を押す**と、次の 2 つから選べます。

- **セッションだけ終了**: 端末を**開き直した状態**に戻します（実行中のプログラムは終了、画面と履歴はクリア）。**常駐サーバーはそのまま動き続けます**。
- **全部停止して終了**: **常駐サーバーもシステムイベント検知も端末も止めてアプリを閉じます**（スワイプで消せないぶんの、確実な終了）。設定は変わらないので、次にアプリを開くと検知は再開します。

「一度まっさらにしたい」ならセッションだけ終了、「全部やめたい」なら全部停止して終了を選んでください。

## 9.5. ホーム画面ウィジェット（アプリを開かずに使う）

ホーム画面に Z2Term の**いまの状態**を出して、**よく使うマクロをタップ 1 回で走らせる**ためのものです。
アプリは開きません（画面が切り替わらず、ホーム画面のまま裏で動きます）。

**置きかた**

1. ホーム画面の空きスペースを長押し →「ウィジェット」
2. 一覧から **Z2Term の状態** を選んでホーム画面に置く
3. 置いた直後に設定画面が出るので、**並べたいマクロを選んで「保存」**（最大 4 個）

マクロが 1 つも無いときは、先に端末で `z2-macro install all` を実行してください
（`~/.z2term/macros/` に入ったものが選べるようになります）。自分で書いた `.sh` を
そのフォルダに置いても、同じように選べます。

**出ているもの**

| 場所 | 内容 |
|---|---|
| 1 行目 | `ssh -p 2222 root@192.168.x.x` … PC からこの端末に入るためのコマンド。**緑色のときは `sshd` が動いています**（灰色なら宛先だけの表示） |
| 2 行目 | `常駐 1/3 · 自動化 2/5 · 電池 87%`（下の表を参照） |
| 右上 | **⚙** … 並べるマクロを選び直す ／ **⟳** … いますぐ最新の状態にする |
| ボタン | 選んだマクロ。タップでバックグラウンド実行。1 行目が名前、**2 行目がそのマクロを今日開始した時刻** |
| ボタンの印 | `■` = 実行中（緑）／ `✓` = 今日走って終わった ／ 印なし = 今日はまだ走っていない |
| 最下行 | 今日、直近に**終わった**マクロと時刻 |

**2 行目の数字の意味**

`1/3` は「**いま動いている数 / 登録してある数**」です。3 つの数はそれぞれ**別のもの**を数えています。

| 表示 | 数えているもの | どこで増やすか |
|---|---|---|
| `常駐 1/3` | 常駐サーバー | 設定 › 常駐サーバー・自動化 › サーバー |
| `自動化 2/5` | 自動化ルール | 端末で `z2-when`（実体は `~/.z2term/when/*.rule`） |
| 下のボタン | マクロ | 端末で `z2-macro`（実体は `~/.z2term/macros/*.sh`） |

つまり **`自動化` の数と、下に並んでいるボタンの数は関係ありません**。
マクロを 4 つ並べても `自動化` は増えませんし、`常駐 0/3` は「3 つ登録してあるが、
いまは 1 つも動いていない」という意味です（常駐サーバーを起動していないときはこうなります）。

**「開始したのにすぐ止まった」ように見えるとき**

そのマクロが**一瞬で終わっているだけ**のことがあります（`echo` するだけのマクロなど）。
`■`（実行中）が消えて `✓` が付いていれば、止められたのではなく**正常に終わっています**。
最下行にも「✓ 名前 HH:MM に終了」と出ます。ずっと動き続けるマクロなら `■` が付いたままになります。

**止めかた**

**実行中のボタンをもう一度タップすると止まります**（`■` が付いている間が実行中）。
ずっと動き続けるマクロ（イベントを見張り続けるものなど）を、ホーム画面から止められます。
なお**アプリを終了すると、ウィジェットから started したマクロもいっしょに終わります**。

**使いかたのコツ**

- 設定画面のマクロ一覧には、**マクロ名の下にそのスクリプトの説明**が出ます
  （スクリプトの先頭に書いたコメントを読んでいます）。自分で `.sh` を書くときも、
  1 行目のシェバン（`#!/bin/sh`）の次に `# なにをするマクロか` と書いておくと、ここに出ます。
- 右上の **⟳ をタップすると、その場で最新の状態に更新**します。ふだんは 30 分ごとに自動更新
  （Android の決まりでこれより短くはできません）。常駐サーバーの起動・停止や、`z2-when`
  ルールを増減したときは、それをきっかけに自動で描き直します。
- 左上の **Z2Term の文字をタップするとアプリが開きます**。
- マクロの出力は `~/.z2term/widget/run.log` に残ります。うまく動かないときは
  端末で `tail ~/.z2term/widget/run.log` を見てください。
- 並べるマクロを変えたいときは、**ウィジェット右上の ⚙ を押す**のが早いです
  （ウィジェットを長押しして設定を開く方法も使えます）。
- **`✓` と時刻は日付が変わると消えます**（翌日には印なしに戻ります）。時刻が `HH:MM` だけなので、
  昨日のものが残っていると「いつの ✓ か」が分からなくなるためです。いま消したいときは
  **⚙ →「実行履歴をリセット」**。マクロ自体は消えません。
- **一覧に出したいマクロを増やすには**、端末で `~/.z2term/macros/` に自分の `.sh` を置くか、
  `z2-macro install all` を実行してから、⚙ を開き直してください。

### もう 1 つのウィジェット: ライブ tail

ファイルの**末尾**または**先頭**をホーム画面に出しておくものです。マクロが何を書いたか、
`z2-when` がいつ動いたかを、**アプリを開かずに**眺められます。

1. ホーム画面の空きスペースを長押し →「ウィジェット」
2. 一覧から **Z2Term ライブ tail** を選んで置く
3. 設定画面が出るので、**見るファイル**と**どちら側を見るか**を決めて「保存」

- ファイルの決め方は 2 通りです。
  - 上の欄に**パスを直接打つ**（`~/.z2term/events.jsonl` のように）
  - 下の一覧で**フォルダをタップして辿り**、目的のファイルをタップする
- **末尾 (tail) か先頭 (head) かを選べます**（0.8.240）。
  - **末尾** … 増え続けるログ向け。新しい行が下に足されていくファイル。
  - **先頭** … 書き終わったファイル向け。レポートや設定ファイルのように**頭に大事なことが書いてある**もの。
  - いま見ているのがどちらかは、ウィジェット下の行に `tail` / `head` と出ます。
- **出す行数はウィジェットの大きさで自動的に決まります**（縦に伸ばせば行が増えます）。
- よく使うのは次のあたりです。
  - `.z2term/widget/run.log` … ウィジェットから走らせたマクロの出力
  - `.z2term/events.jsonl` … 検知したイベント（画面 ON/OFF・充電・Wi-Fi など）
  - `.z2term/when/<id>.log` … その自動化ルールが実行した記録
- **⟳** でその場で読み直します。ふだんは 30 分ごとの自動更新に加えて、
  **マクロや自動化ルールの実行が終わったとき**にも自動で描き直します。
- **⚙** で見るファイルを変えられます。
- ファイルが大きくなっても**選んだ側の一部だけ**を読むので重くなりません。

## 10. 困ったとき (FAQ)

**Q. `sshd` がうまく動かない / ポートがおかしい**
→ `sshd`（フルパスの `/usr/sbin/sshd` ではなく）と打ってください。ポートは `/etc/ssh/sshd_config` の `Port`、または `sshd -p 番号` で。1024 以上にしてください。

**Q. 日本語が打てない**
→ キーボード左の「あ」キーで日本語フリックに切替。かなを打つと候補バーが出るので「変換」キーや候補タップで漢字にできます（長い文は自動でかたまりごとに予測）。もっと賢い変換が欲しいときはツールバーの「⌨」でスマホ標準キーボード (Gboard など) に切替できます。

**Q. 文字をうまく選べない / 端まで選べない**
→ 長押ししてから指でなぞります。端まで行きたいときは指を画面の上端/下端へ寄せると自動スクロールします。選択の端の近くをドラッグすると範囲を変えられます。

**Q. アプリを更新したら常駐サーバー（sshd など）が止まっていた**
→ **仕様です。** アプリを入れ替えると Android がそのアプリを一度終了させるため、常駐していたサーバーもまとめて止まります。「起動時に自動で常駐」は**端末（スマホ）を起動したとき**に効く設定なので、アプリの更新では復帰しません。更新のあとは ⚙設定 →「常駐サーバー・自動化」→「常駐サーバー」→「サーバーを管理」→「**起動**」を押し直してください。

**Q. アプリを閉じたら端末が止まる**
→ ツールバーの **🔒（バックグラウンド常駐）**を ON に（🔒 表示で ON）。

**Q. `cd /sdcard` で中身が見えない**
→ ⚙設定の「ストレージ全体を許可」で権限を ON にしてください。

**Q. `ping` が動かない**
→ スマホの仕組み上できません。`curl` で疎通確認、ポートスキャンは `nmap -sT` を使ってください。

**Q. GUI アプリが `segmentation fault` だけ出して起動しない**
→ **0.8.177 で修正済み**です。アプリを更新してから、その OS のタブを一度閉じて開き直してください。原因は共有メモリの置き場（`/dev/shm`）がスマホの仕組み上そのままでは用意されないことで、これを前提に作られている GUI アプリ（メールソフトやブラウザなど）が起動の途中で自分から終了していました。理由が表示されないため「ただ落ちた」ように見えます。更新後も同じなら、`ls -d /dev/shm` で存在を確認のうえ開発者にお知らせください。

**Q. GUI アプリの本文やページの表示だけが真っ白／子プロセスが落ちる**
→ **0.8.179 で修正済み**です。アプリを更新してから、その OS のタブを一度閉じて開き直してください。

Web の描画エンジン（Gecko 系）を使うアプリで起きていました。アプリ本体の枠や設定画面はきちんと出るのに、**中身を描く担当の子プロセスだけ**が落ちて、本文のペインが空白のままになります（`unable to find a usable font`）。原因はそのエンジンが持つ独自のサンドボックスと z2term 側の噛み合わせで、**アプリ側の防御はそのままで直りました**。

更新後も同じ症状が出る場合は、応急処置としてサンドボックスを切って起動できます。

```sh
MOZ_DISABLE_CONTENT_SANDBOX=1 <アプリ名>
```

ただし**アプリ側の防御が 1 枚無くなる**ので、信用できない差出人の HTML メールや知らないサイトを開くときは、その分のリスクがあることを承知のうえで使ってください。恒久的に使うものではなく、症状が出たら開発者にお知らせいただけると助かります。

**Q. GUI の描画がもたつく**
→ スマホのカーネルが SysV 共有メモリ（`shmget`）を持っていないため、X11 の高速描画（MIT-SHM）が使えないのが理由です。仕組み上の制約で、こちらは修正できません。たいていのアプリは自動で別の方法に切り替わるので「動くが少し遅い」で済みます。表示が崩れるアプリがあれば、そのアプリの設定で MIT-SHM（共有メモリ）を切ってみてください。

## 11. Z2Term 独自コマンド早見表（`z2*`）

Z2Term がどのディストロにも自動で入れてくれる「Z2Term 専用コマンド」です。端末でそのまま打てます（PATH 上にあるので場所は気にしなくて OK）。アプリを起動するたび最新版に書き直されます。

### 版数・情報
| コマンド | できること |
|---|---|
| `z2version` | いま動いているアプリの版数・実行エンジン・OS（ディストロ）・kernel を表示。`z2version --short` は版数だけ 1 行 |

### スマホの機能を呼ぶ
| コマンド | できること |
|---|---|
| `z2-notify [-h] [-n 名前] [-b ラベル]... "タイトル" "本文"` | 通知を出す（本文は省略可。`-h` で画面上部にバナー表示）。**`-b` で返事のボタンを付けられます**（最大3つ）。押すと `events.jsonl` に `notify_action` が 1 行増えるので、マクロ側で返事を受け取れます |
| `z2-ask [-t 秒] [-H ヒント] [-d 既定] "質問"` | **質問して、答えを受け取ります**（0.8.267）。質問は**返信欄つきの通知**で届くので、アプリを開かずシェードのまま答えられます。答えは標準出力に出るので `name=$(z2-ask "ブランチ名は?")` と受け取れます。答えずに通知を消したときと時間切れ（既定 5 分）は**何も出さずに失敗**するので、`|| exit` で「答えなければ諦める」と書けます。選択肢から選ばせたいだけなら `z2-notify -b` の方が向いています |

| `z2-share "テキスト"` | Android の共有メニューに渡す |
| `z2-open <URL かパス>` | URL やファイルを既定アプリで開く |
| `z2-clip get` / `z2-clip set [テキスト]` | クリップボードの取得／設定（set は引数なしだと標準入力から） |
| `z2-battery` | 電池残量・充電状態を表示（JSON） |
| `z2-vibrate [ミリ秒]` | バイブ（既定 200ms） |
| `z2-say <テキスト>` | 端末標準の音声合成（TTS）で読み上げ（引数なしだと標準入力から） |
| `z2-torch [on\|off\|toggle]` | フラッシュライトを点灯／消灯／切替（既定 toggle。結果の状態を出力） |
| `z2-media [playpause\|play\|pause\|next\|previous\|stop]` | メディア再生を操作（既定 playpause） |
| `z2-volume <up\|down\|mute\|unmute\|N\|N%>` | メディア音量を操作（結果の current/max を出力） |
| `z2-sensor [light\|accel\|proximity]` | センサーを1回読んで JSON 出力（照度/加速度/近接。既定 light） |
| `z2-state [キー]` | **今の端末の状態**を JSON で出力。キーを付けるとその値だけ（`screen` `locked` `idle` `charging` `plug` `level` `temp` `wifi` `ssid` `ringer` `airplane` `headset` `bt_audio` `volume` `volume_max`）。例: `[ "$(z2-state charging)" = "true" ]` |
| `z2-screen keepon <1h\|30m\|90s>` | **その時間だけ、画面が自分で消えないようにする**（`keepon off` で期限を待たず戻す、`status` で残り時間）。OS 全体の「画面消灯までの時間」を変えるので**アプリを畳んでいても効きます**。⚠ ツールバーの 🔅（アプリを開いている間だけ）とは別物です。元の値は期限が来たら必ず書き戻します（アプリが落ちても・再起動しても）。一度に掛けられるのは 24h まで。**「システム設定の変更」の許可が要ります**（設定 › 画面の自動消灯） |
| `z2-tile set <1-12> <マクロ.sh\|コマンド>` | **クイック設定パネルにマクロ / コマンドを置く**（`list` / `clear <1-12\|all>`、表示名は `-l`）。押すと実行、もう一度押すと停止（ウィジェットのボタンと同じ約束）。実行中はタイルが ON の見た目になります（色は OS のもの）。ロック中は Android が先に解除を求めます。⚠ **枠はちょうど 12**（0.8.294 に 4 から拡張。実行中に増やせない Android の仕様なので、多めに用意してあります）。**まだ何も割り当てていない枠はクイック設定の一覧に出ません**（0.8.271 から**1 つも割り当てていなければ 1 枚も出ません**。それまでは枠 1 だけ目印として残っていました）。⚠ **タイルを並べるのはご自身**で、クイック設定の鉛筆（編集）から追加します（アプリが勝手に置くことは OS が禁じています）。⚠ 割り当てを `clear` すると、**並べてあったタイルもパネルから外れます**（もう一度割り当てても並べ直しになります）。**`z2-screen keepon` を割り当てた枠だけは特別**で、ON の見た目が「消灯しないが掛かっている間」を表し、**名前の後ろに残り時間**が出ます（例:「消灯しない 60分」。押すと解除。残りはパネルを開いた時点の値で、開いている間は進みません）。**切るのが別コマンドのものは `--off` で 1 枚に**できます（`z2-tile set 3 z2-torch on --off z2-torch off -l ライト`）。押すたびに交互に走り、入の間は ON の見た目。⚠ この入 / 切は**アプリが覚えているだけ**なので、端末から直接 `z2-torch off` を打つとタイルは入のままになります。**マクロには引数を渡せます**（`z2-tile set 2 'remind.sh ask' -l リマインド`。0.8.275。マクロかどうかは**先頭の語**で決まります）。同じマクロを 2 枠に置くと表示名が同じになるので `-l` を付けてください。⚠ `.sh` で終わるのに `~/.z2term/macros/` に無い名前は**登録時に断ります**（通すとコマンド扱いで見つからず、押しても無反応になるため）。マクロ置き場の外のスクリプトはフルパスで書きます。**押しても何も起きないときは `~/.z2term/tile/run.log`** を見てください（失敗は画面に出ません） |
| `z2-icon pick <notify\|1-12>` | **ステータスバーとタイルのアイコンを自分の絵に差し替える**（0.8.294）。**タイルは、割り当てた名前から分かるものに自動で絵が付きます**（0.8.299。`remind.sh` なら時計、`battery-alert.sh` なら電池）。自分で入れた絵はそれより優先され、以後は自動で触りません。**自動に戻したくなったら `z2-icon auto <枠\|all>`**（自分で入れた絵も上書きして選び直します）。**`z2-icon list` を見れば、どの枠にどの絵が入っているかが名前で分かります**（0.8.300。`auto` が自動で付いたもの、`custom` が自分で入れたもの。`z2-icon list -p` なら絵そのものも並びます）。一覧から番号で選ぶだけです（`z2-icon sample` で一覧、`z2-icon sample <対象> <名前>` で直接指定）。**自分で描いた絵は、名前を付けて一覧に残せます**（0.8.300。`z2-icon save <対象> <名前>` で足すと、以後は同梱の絵とまったく同じように番号でも名前でも選べるので、別の枠にも同じ絵を入れられます。`z2-icon forget <名前>` で一覧から下げます — すでに入れてある絵はそのまま残ります）。自分で描くなら `z2-icon edit <対象>` — `$EDITOR` が開くので、`#` と `.` で 24x24 のマス目を描いて保存すると即反映されます（`.` ` ` `0` `-` `_` が空きマス、**それ以外の字はすべて塗り**なので見やすい字で描けます）。まわりの余白は無視して中央に置き直すので、24 行きっちりに合わせる必要はありません。ファイルから入れるなら `z2-icon set <対象> <ファイル>`（`-` で標準入力）、いまの絵を見るなら `z2-icon show <対象>`、元に戻すなら `z2-icon clear <対象\|all>`。対象は **`notify`（このアプリが出す通知すべてに使う 1 枚）** と **枠番号 1〜12（タイルは枠ごとに別の絵）**。⚠ **色は付きません** — Android がこれらのアイコンを単色で塗り直すため（タイルは入 / 切で色が変わります）、決まるのは形だけです。⚠ 表示は 24px 前後なので、細かい描き込みは消えます（`show` で見えるものがそのまま出ます）。⚠ **変えられない場所が 3 つあります**: クイック設定の**編集画面**（タイルを引っぱり出すところ）のアイコン、**ファイル選択のルートアイコン**、**ランチャーアイコン**。Android が導入時に固定するためで、並べた後のタイルと実際に出る通知は変わります |
| `z2-alarm at\|daily HH:MM [名前]` | **時刻トリガー**。その時刻に `events.jsonl` へ `alarm` イベントを書く（`in 5m` / `list` / `cancel <id\|名前\|all>` も）。cron と違い Doze 中でも起きる（数分ずれることあり）。⚠ **0.8.302 より前は、端末の中の時計が UTC 固定**だったため、`18:30` のような時刻の指定が時差のぶんずれていました（日本なら 9 時間）。0.8.302 からは端末と同じ時刻で動きます。**古い版で予約したものは登録し直してください** |
| `z2-session list\|new\|send\|capture\|close` | **このアプリのタブを操る**。`list` で一覧（番号・id・名前・印。`*`=表示中 `!`=動作中 `?`=未起動）、`new [名前]` でタブを 1 枚追加、`send <先> "文字列"` でそのタブに**入れるだけ**（`--enter` を付けたときだけ実行）、`capture [先]` で画面のテキストを取り出し、`close <先>` で閉じる。`<先>` は `list` の番号 / id / タブ名。例: ``n=$(z2-session new build \| cut -f1); z2-session send "$n" 'make -j2' --enter`` |
| `z2-session key <先> <キー>...` | **そのタブにキーを送る**（0.8.311）。`z2-session key 2 C-c` で Ctrl+C、`M-x` で Alt+x、`F5` `Up` `Home` などの特殊キーも。まとめて `key 2 F5 Up Home` と書けます。表に無いものは `key 2 --raw '\x1b[A'` とバイト列で。⚠ **`send` では Ctrl+C は送れません**（あちらは貼り付けなので、`^C` という文字が入るだけです）。⚠ `C-S-a` のような **Shift 付きは断ります** — 端末は Shift を区別できず `C-a` と同じものになるためです（`S-Tab` だけは区別できるので送れます） |
| `z2-server list\|start\|stop\|status <サーバー>` | **登録済みの常駐サーバー**を起こす / 落とす。⚠ ルールから直接 `sshd` などを起こすと**常駐の枠の外**で動くので、画面を消すと届かなくなります。ここから起こすと枠の中に入ります。`<サーバー>` は `list` の番号 / id / アプリで付けた名前。例: `z2-when wifi:connect run 'z2-server start sshd'` |
| `z2-when <トリガー> run <コマンド>` | **自動化ハブ**。充電・電池・時刻・端末イベントをきっかけにコマンドを自動実行（下記「自動化ハブ」参照）。`list` / `remove <id\|all>` / `on\|off <id>` / `log <id>` も。例: `z2-when charge:start run ~/.z2term/macros/backup.sh` |
| `z2-macro list\|install <名前>` | **マクロのサンプル**を `~/.z2term/macros/` に導入（`show` / `run` / `dir` も）。最初の1本の雛形に。同梱は `watch-basic` / `battery-alert` / `daily-report` / `otp-clip` / `otp-sms` / `unknown-call` / `remind` / `rss` / `rss-open` / `qr`。導入すると**そのスクリプトの動かし方**（`z2-when` で回す／ウィジェットのボタンに割り当てる／常駐サーバーに登録する）が表示されます。⚠ **常駐サーバーに登録してよいのは `watch-basic` だけ**です（0.8.273。他は `z2-when` やボタンから 1 回走って終わる形なので、常駐にすると終わるたびに再起動されるうえ、待っているだけで電池を使います） |
| `z2-intent [-a ACTION] [-d URI] [-p PKG] [-n PKG/CLS] …` | 任意の Android Intent を発火（アプリ起動・設定画面・アラーム設定など。詳細は `docs/ja/MACRO-GUIDE.md`） |

> 「トリガー（イベント検知）→ 判断（シェル）→ アクション（z2-*）」でスマホの自動化（マクロ）が組めます。書き方は **`docs/ja/MACRO-GUIDE.md`**（AI に読ませてそのままマクロ生成させることもできます）。

### 通知でリマインドを受け取る

**アプリに予定表は入っていません。** 時刻トリガー・通知・タイルという**既にある部品**を組み合わせた
サンプル（`remind`）で、**アプリを閉じていても鳴る**リマインダーになります（0.8.275）。

```sh
z2-macro install remind                  # 入れる
sh ~/.z2term/macros/remind.sh setup      # 最初に 1 回だけ（受け口とタイルを登録）
```

**足す**

```sh
remind.sh 30m 薬を飲む             # 30 分後に 1 回（90s / 2h も可）
remind.sh 18:30 ゴミ出し           # 次の 18:30 に 1 回（過ぎていれば明日）
remind.sh 明日 18:30 ゴミ出し      # 明日の 18:30 に 1 回
remind.sh 明後日 電話する           # 明後日の「今と同じ時刻」に 1 回
remind.sh 3日後 07:00 返却         # N 日後（`3日後の07:00` `3d 07:00` も同じ）
remind.sh 07/30 19:00 花火大会      # 月日（過ぎていれば来年）
remind.sh 2027 07/30 19:00 記念日   # 年つき
remind.sh 202707301900 記念日       # 数字だけ（07301900 = 月日時分 も可）
remind.sh 毎日 07:00 体重を計る     # 毎日
remind.sh 平日 09:00 朝会           # 月〜金
remind.sh 毎週 火 20:00 燃えるゴミ  # その曜日だけ
remind.sh 毎月 25 10:00 家賃        # 毎月その日（毎月25日 10:00 も同じ）
remind.sh 毎年 07/30 19:00 誕生日   # 毎年その月日
remind.sh 毎 19:00 / 毎 水 19:00    # 「毎」だけでも書ける（次の語で決まる）
remind.sh 毎 15 19:00 / 毎 07/30 19:00   #  → 毎日 / 毎週 / 毎月 / 毎年
```

**書き方を忘れたら**: `remind.sh help` で一覧が出ます（📜 のスニペットにも入っています）。
⚠ **`remind.sh: command not found` と出たら、そのタブが古い PATH のままです**（0.8.287 でマクロ置き場を
PATH に入れました）。**新しいタブを開く**か、そのタブで `export PATH=$HOME/.z2term/macros:$PATH` を打ってください。

**見る・消す**: `remind.sh list`（⏰ = 単発 / 🔁 = 繰り返し / ✔ = 通知済）、`remind.sh del 2`（`del all` で全部）。
⚠ **クイック設定の「予定」タイルからも消せます**（0.8.286）。押すと一覧が通知で出るので、**[消す]** を押して番号（または `all`）を答えます。
繰り返しは 📜 →「自動化」タブにも並ぶので、そこから ON/OFF や ▶ での試し打ちもできます。

**鳴ったら**: 通知に **[完了] [10分後] [1時間後]** が付きます。シェードから指 1 本でスヌーズでき、
繰り返しの予定は「完了」を押しても明日また鳴ります。

**アプリを開かずに足す**: `setup` がクイック設定タイルを 2 枚（「リマインド」「予定」）用意します。
⚠ **並べるのはご自身**で、クイック設定パネルの鉛筆（編集）から追加してください。⚠ **タイルを押すとクイック設定パネルは自動で閉じます**（0.8.284）。閉じないと、聞き返しの通知がパネルの下に隠れて答えられないためです。「リマインド」を押すと
返信欄つきの通知で「何をリマインド？」「いつ？」と聞いてくるので、**アプリを開かずに登録できます**。
⚠ **「いつ？」に書き方が違うものを入れたときは、何が駄目かを付けて聞き直します**（0.8.283）。
前に書いた内容が返信欄に残るので直すだけで済みます。3 回とも読めなければ諦めて「登録できませんでした」と
知らせます（それまでは黙って終わっていて、押しても何も起きないように見えていました）。
**登録できたときも通知で「⏰ 登録しました」と予定・本文を出します**。

- **日付でも書けます**（0.8.285）。`明日` `あした` `翌日` `明後日` `あさって` `N日後`（`3d` も可）。
  **時刻を省くと「今と同じ時刻」**になります（勝手に朝 9 時などにしません）。⚠ 一覧には `07/31 18:30` の
  ように**実際の日付**で出ます（「明日」のまま覚えると、日付が変わった後にズレて見えるためです）。
- **書き方が違うものは登録しません**（0.8.283）。`18:70`（範囲外）、`毎日`（時刻なし）、`1.5h`（数でない）、
  読めない曜日などは、理由を出して断ります。端末から打ったときも同じ理由が出ます。
- **時刻は数分ずれることがあります**（省電力の眠り＝Doze に合わせた予約のため）。秒単位の正確さが要る
  用途には向きません。
- 端末を再起動しても予定は残ります。
- 中身の作りは `docs/ja/MACRO-GUIDE.md` の「5-9. 実例：通知でリマインドする」を参照。

### フィードを購読する（RSS / Atom）

**アプリに RSS リーダーは入っていません。** 代わりに、定期実行・通知・ブラウザで開く・ウィジェットという**既にある部品**を組み合わせて作ります。用途が違えば書き換えられるのが利点です。

```sh
z2-macro install rss rss-open        # 集める側と開く側を入れる
python3 -V || apk add python3        # 解析に python3 が要ります（Debian: apt-get install -y python3 / Arch: pacman -S python）
```

**1. 読みたい URL を書く** — `~/.z2term/rss/feeds.txt` に 1 行 1 本（`#` で始まる行は無視）。

**2. 定期的に取りに行かせる**

```sh
z2-when time:every=30m run ~/.z2term/macros/rss.sh
```

新着があったときだけ「新着 N 件」と通知が出ます。**30 分より短くしないでください**（そのぶん電池を食います）。

**集めた記事を一覧で読む**（0.8.255）

```sh
sh ~/.z2term/macros/rss.sh list       # 20 件
sh ~/.z2term/macros/rss.sh list 50    # 件数を指定
```

`[ 1] 記事の題名  (zenn.dev)` のように 1 行 1 記事で並びます。**題名をタップするとその記事が開きます**（URL は表示しません — 長い URL が折り返して題名と混ざり、一覧として読めなくなるためです）。パイプやリダイレクトに流したときは、素のテキストに URL 付きで出ます。

**3. 通知の「開く」で最新の 1 本をブラウザへ**（任意）

```sh
z2-when event:notify_action run '[ "$Z2_WHEN_EVENT_NAME" = rss ] && z2-open "$(head -1 ~/.z2term/rss/new.txt | cut -f1)"'
```

**4. ウィジェットで読む**（任意）

- **ライブ tail ウィジェット**で `~/.z2term/rss/latest.txt` を「**先頭 (head)**」表示にすると、新しい記事が上に並びます
- **状態ウィジェット**のボタンに `rss-open` を割り当てると、**押すたびに次の 1 本**がブラウザで開きます（開いたものは覚えているので、同じ記事が何度も開きません）

できるファイルはどれもただのテキストです。

| ファイル | 中身 |
|---|---|
| `~/.z2term/rss/feeds.txt` | 読みたいフィードの URL（自分で書く） |
| `~/.z2term/rss/latest.txt` | 「タイトル  URL」を新しい順に。読むのはこれ |
| `~/.z2term/rss/new.txt` | 直近の取得で増えた分だけ |
| `~/.z2term/rss/seen.txt` | 既に見た記事（新着の判定に使う） |
| `~/.z2term/rss/opened.txt` | `rss-open` で開いた記事 |

全部消せば最初からやり直せます。1 本のフィードが落ちていても他は続きます。壊れた XML は黙って飛ばします。

### QR にして別の端末へ渡す（0.8.308）

長い URL や設定を**別の端末へ打ち直さずに渡す**ためのサンプルです。画面に QR を出して、相手のカメラで読んでもらいます。

```sh
z2-macro install qr                  # 入れる
apk add libqrencode-tools            # Alpine（Arch: pacman -S qrencode / Ubuntu・Kali: apt install qrencode）

qr.sh "https://example.com"          # 文字列を QR にして画面に出す
qr.sh -f notes.txt                   # ファイルの中身を QR にする
z2-clip get | qr.sh                  # いまコピーしているものを QR にする
qr.sh -o ~/qr.png "text"             # PNG に保存する（画面には出さない）
qr.sh -t "text"                      # 絵ではなく文字（ブロック）で出す
qr.sh -h                             # 説明を全部見る
```

- ⚠ **QR を作る `qrencode` は自分で入れます**（タブごとに 1 回）。入っていなければ、そのタブでの入れ方を出して止まります。
- ⚠ **絵で出せるのはこのアプリのタブの中だけ**です。`ssh` で入った先など画像を出せない端末では意味不明な文字が流れるので、`-t` を付けて文字で出してください。
- ⚠ **カメラで読ませるなら絵か PNG が確実**です。文字（`-t`）はフォントによって行の間に隙間が出て、目で読めてもカメラが読み取れないことがあります。
- 長い入力は**行の切れ目で自動的に何枚かに分かれ**、`[1/3]` と番号が付きます。順に読ませてください。
- 潰れて見えるときは `Z2_QR_ASPECT=0.45 qr.sh "text"` のように縦横比を微調整できます（小さいほど縦長。既定 0.5）。

### 自動化ハブ（`z2-when`）

**充電した / 電池が減った / 決まった時刻になった**、をきっかけにコマンドを自動で実行します。イベントの検知を自分で `tail` して書く必要がなく、**宣言するだけ**で動きます。アプリを開いていなくても・再起動をまたいでも働きます。
**ただし時刻・SMS・通知以外のトリガー（充電・電池・Wi‑Fi・センサー・新しいファイル・端末イベント）は「検知」を ON にしている間だけ働きます**（設定の常駐・自動化）。Android の仕組み上、これらの出来事はアプリが常駐していないと受け取れません。SMS は SMS 受信の許可、通知（`notify:`）は通知アクセスの許可が前提です。

**サーバーを起こすルールも書けます**（`z2-when wifi:connect run 'sshd --lan'` など）。起こしたサーバーはルールの実行が終わっても**動いたまま**残ります（0.8.253 で修正。それ以前は実行が終わった瞬間に道連れで止まり、ログに「listening」と出るのに繋がりませんでした）。⚠ ただし残るのは**アプリが動いている間**だけです。ずっと上げておきたいものは**常駐サーバー**に登録してください。

**画面からも作れます**（0.8.272）。📜 →「自動化」タブの **＋ 新規** できっかけを候補から選び、コマンドを書いて保存するだけです。既にあるルールは **✎** で開くと、コマンドの全文・絞り込み（`if` / `cooldown` / `between` / `days`）がそのまま出て直せます。コマンドがスクリプト 1 本を指しているときは**その中身も表示**されます（直すのは端末で）。端末で `z2-when` を打って作ったルールも同じように直せます — どちらも同じファイル（`~/.z2term/when/*.rule`）を見ているためです。

**名前を付けられます**（0.8.303）。フォームのいちばん上が「名前」です。付けると一覧の見出しがその名前になり（きっかけはその下に小さく残ります）、直近の発火もその名前で出ます。`event:screen_on` のような同じきっかけのルールが並んでも見分けが付きます。**空欄のままなら今までどおりきっかけが見出し**になります。名前は表示だけのもので、いつ動くかは一切変わりません。端末から付けるときは `z2-when time:daily=07:00 name='朝の日報' run ~/.z2term/macros/report.sh` のように、きっかけの直後・`run` より前に置きます（空白を含むならクォートで囲みます）。

⚠ **コマンドは必ず 1 行です**。ルールのファイルは 1 行 1 項目なので、**改行が入るとそこから先が捨てられます**（折り返して貼り付けたコマンドが途中で切れ、動かないルールになります）。0.8.272 からは画面でも `z2-when` でも**改行を空白に直して**登録するので事故りませんが、長いものは**スクリプトファイルに書いて、そのパスを登録する**のが確実です。

登録の書き方（トリガーとコマンドを並べるだけ）:

```sh
z2-when charge:start        run ~/.z2term/macros/backup.sh   # 充電を始めたらバックアップ
z2-when battery:below=20    run "z2-notify -h '電池 20% 切りました'"
z2-when time:daily=03:00    run ~/.z2term/macros/nightly.sh  # 毎日 3:00
z2-when time:cron='0 9 * * 1-5' run ~/.z2term/macros/weekday.sh  # 平日 9:00
z2-when wifi:ssid=home       run ~/.z2term/macros/expose-lan.sh # 自宅 Wi‑Fi に繋いだら
z2-when sms:otp              run 'echo "$Z2_WHEN_OTP" | z2-clip'  # 届いた OTP をクリップボードへ
z2-when sensor:shake         run ~/.z2term/macros/panic.sh        # 端末を振ったら
z2-when event:headset_plugged run ~/.z2term/macros/play.sh        # イヤホンを挿したら
z2-when 'event:ringer_*'      run 'z2-toast "$Z2_WHEN_EVENT"'     # マナーモードを切り替えたら
```

- **トリガーの種類**
  - `charge:start` / `charge:stop` … 充電の開始 / 停止。**「検知」を ON にしているときだけ働きます**（設定の常駐・自動化）
  - `battery:below=N` / `battery:above=N` … 残量が N% を**下/上へ跨いだ瞬間**（例: 20 を切った時）。こちらも**「検知」が ON のときだけ**働きます
  - `time:daily=HH:MM`（毎日）/ `time:at=HH:MM`（次の HH:MM に 1 回だけ。実行後は自動で無効になります）/ `time:every=30m`・`2h`（一定間隔・最短 1 分）
  - `time:cron='分 時 日 月 曜日'` … cron 式で細かく指定（例: `'0 3 * * *'` 毎日 3:00 / `'*/15 * * * *'` 15 分ごと / `'0 9 * * 1-5'` 平日 9:00）。曜日は 0〜7（0 と 7 が日曜）。**空白を含むので必ずクォート**してください
  - `wifi:connect` / `wifi:disconnect` / `wifi:ssid=<名前>` … Wi‑Fi に接続 / 切断 / 指定のネットワークに接続したとき。**この Wi‑Fi トリガーは「検知」を ON にしているときだけ働きます**（設定の常駐・自動化）。ネットワーク名（SSID）を使うには位置情報の許可も要ります。コマンド内では `Z2_WHEN_SSID` に接続先の名前が入ります
  - `net:online` / `net:offline` … **通信できる回線ができた / 無くなった**とき（0.8.264 で追加）。`net:wifi` / `net:mobile` / `net:ethernet` と書くと、**使う回線がそれに切り替わった**ときです。Wi‑Fi トリガーとの違いは**モバイル回線も見る**こと — 「Wi‑Fi が切れた」だけでは、そのあとモバイルで繋がっているのか本当に圏外なのかが分かりません。「繋がったらまとめて送る」「圏外になったら止める」はこちらで書きます。**「検知」が ON のときだけ**働きます。コマンド内では `Z2_WHEN_NET`（今の回線）と `Z2_WHEN_NET_PREV`（直前の回線）が使えます。⚠ Wi‑Fi からモバイルへ変わっても「通信できる」ことは変わらないので、`net:online` は**そこでは動きません**（変化した所だけを見ています）。⚠ **本当に通信できたか**を確かめてから動くので、Wi‑Fi のアイコンが立つより**数秒遅れます**（繋がっているのに通らない、を「オンライン」と呼ばないため）
  - `share:any` / `share:text` / `share:file` / `share:contains=<部分>` / `share:ext=<拡張子>` … **他のアプリから「共有」で z2term へ送ったとき**（0.8.266 で追加）。例: ブラウザから URL を共有したら裏でダウンロード、`z2-when share:ext=pdf run ~/.z2term/macros/pdf.sh`。**「検知」が OFF でも働きます**。コマンド内では `Z2_WHEN_SHARE`（テキストそのもの、またはファイルの取り込み先パス）と `Z2_WHEN_SHARE_KIND`（`text` か `file`）が使えます。⚠ **ファイルのときの `Z2_WHEN_SHARE` は「パス」ではなく「シェルに貼るための文字列」です**（`~` が展開されていない・空白を含む名前は引用符つき・複数ファイルは空白区切り）。`[ -f "$Z2_WHEN_SHARE" ]` と書くと必ず外れます。分解のしかたは `docs/ja/MACRO-GUIDE.md` の「⚠ `share:` で渡ってくる文字列の形」にそのまま貼れる例があります。⚠ 共有されたものは**今までどおり入力行にも入ります**（ルールを書いても、そこは変わりません）。⚠ 共有すると **z2term の画面が開きます**（共有の宛先はアプリの画面なので、Android の作り上そうなります）。
  - `boot` … **端末を起動したとき**（0.8.264 で追加。`:` は付けません）。例: `z2-when boot run 'sshd --lan'`。時刻や SMS と同じで、**「検知」が OFF でも働きます**。⚠ ロックを一度も解除していない状態では動かず、解除後の起動完了を待ちます（それより前はアプリのファイルがまだ読めないため）
  - `sms:any` / `sms:from=<部分>` / `sms:contains=<部分>` / `sms:otp` … SMS を受信したとき（すべて / 送信元に一致 / 本文に含む / OTP らしい数字コードがあるとき）。**SMS の受信許可（設定の「SMS 検知」で許可）が要ります**。コマンド内では `Z2_WHEN_SMS_FROM`・`Z2_WHEN_SMS_BODY`、`sms:otp` のときは抜き出したコードが `Z2_WHEN_OTP` に入ります。SMS を直接読むので、Android 15 の OTP 伏せ字の影響を受けません
  - `sensor:shake` / `sensor:light>N` / `sensor:light<N` / `sensor:proximity=near` / `sensor:proximity=far` … 端末を振ったとき / 明るさ（照度 lux）が N を上・下へ跨いだとき / 近接センサーが近づいた・離れたとき。**この sensor トリガーは「検知」を ON にしているときだけ働きます**。`shake` は**しっかり振ったとき**だけ反応します（歩いているだけで反応しないよう強めに設定してあります。連続して振っても 3 秒に 1 回までです）。センサーは電池を使うので、使うルールがあるセンサーだけを動かします（使っていなければ電池は消費しません）。コマンド内では `Z2_WHEN_SENSOR`（どのセンサーか）、light は `Z2_WHEN_LUX`（そのときの照度）が入ります
  - `notify:any` / `notify:otp` / `notify:pkg=<部分>` / `notify:title=<部分>` / `notify:contains=<部分>` … **通知が届いたとき**（0.8.236 で追加）。SMS 以外で届く確認コード（メール・認証アプリ）を拾うのに使えます。例: `z2-when notify:otp run 'echo "$Z2_WHEN_OTP" | z2-clip set'`。コマンド内では `Z2_WHEN_NOTI_PKG`・`_APP`・`_TITLE`・`_TEXT` が使えます。**通知アクセスの許可**が要ります（設定 › 常駐サーバー・自動化 › 通知検知）。通知の記録を OFF にしていても働きます。
  - `file:new=<フォルダ>` / `file:new=<フォルダ>,ext=<拡張子>` … **そのフォルダに新しいファイルが来たとき**（0.8.235 で追加。例: `z2-when file:new=/sdcard/Pictures/Screenshots run ~/.z2term/macros/shot.sh`）。コマンド内では `Z2_WHEN_FILE`（フルパス）と `Z2_WHEN_DIR` が使えます。**書き込みが終わってから**動くので、コピー途中のファイルを掴みません。**「検知」が ON のときだけ**働きます。
  - `event:<名前>` … **端末で起きたことを名前で拾います**（0.8.226 で追加）。使える名前は **`z2-when events`** で一覧できます（`screen_on`・`unlocked`・`headset_plugged`・`bt_audio_connected`・`ringer_silent`・`airplane_on`・`alarm`・`notify_action` など約20種）。`event:ringer_*` のように**末尾を `*`** にすると前方一致、`event:*` ですべてになります。コマンド内では `Z2_WHEN_EVENT` にイベント名が入ります。
    **同じルールは 10 秒以内に続けて発火しません**（`screen_on` のように何度も起きるものがあるため）。
    画面・充電・Wi‑Fi などの受け身のイベントは**「検知」が ON のときだけ**ですが、`alarm`（`z2-alarm` で仕掛けたもの）や `notify_action`（通知のボタン）は**検知 OFF でも働きます**。
- **打ち間違いはその場で教えてくれます**（0.8.265）: `z2-when net:onlien …` のようにきっかけの綴りを間違えると、**登録せずにエラーを出します**。登録できてしまうと「並んでいるのに一生動かないルール」になり、原因が分からなくなるためです。
- **条件を付けて絞り込む**（0.8.263）: きっかけの**直後**（`run` より前）に置くと、**どのきっかけにも同じように効きます**。組み合わせて使えます。
  - `if=<条件>` … **そのときの端末の状態**が合っているときだけ実行します。カンマで区切ると「かつ」、頭に `!` を付けると否定です。書ける条件は `z2-state` で見られる項目そのもの（`wifi` `charging` `screen` `locked` `headset` `bt_audio` `airplane` `idle` / `ssid=` `ringer=` `plug=` / `level<30` `temp>40` `volume>0`）。例: `if=wifi,!screen`（Wi‑Fi に繋がっていて画面が消えているとき）/ `if=ssid=Home`（自宅の Wi‑Fi のときだけ）/ `if=level<30`（電池が 30% 未満のとき）
  - `cooldown=<時間>` … **前に実行してからこの時間は動かしません**（`30s` / `10m` / `2h`。単位を省くと分）。`sensor:shake` のように何度も来るきっかけで効きます
  - `between=HH:MM-HH:MM` … **その時間帯だけ**実行します。`22:00-07:00` のように**日をまたいでも**書けます（開始の時刻は含み、終了の時刻は含みません）
  - `days=mon-fri` … **その曜日だけ**実行します。`sat,sun` のように並べても、`1-5` のように cron と同じ数字（0 と 7 が日曜）でも書けます

  ```sh
  # 自宅の Wi-Fi で充電を始めたときだけバックアップ（1 時間に 1 回まで）
  z2-when charge:start if=ssid=Home cooldown=1h run ~/.z2term/macros/backup.sh
  # 平日の夜だけ、画面が消えていたら実行
  z2-when time:every=30m if=!screen between=22:00-07:00 days=mon-fri run ~/.z2term/macros/nightly.sh
  ```

  **弾いたことも記録されます** — `z2-when fired` や画面の「直近の発火」に `skip:if` / `skip:cooldown` / `skip:between` / `skip:days` と出るので、「動かない」ではなく「**なぜ動かなかったか**」が分かります。画面の **▶（1 回試す）はこの絞り込みを無視**します（試すためのボタンなので）。
- **画面から見る・止める**（0.8.227）: 📜 →「**自動化**」タブに登録したルールが並びます。各行で ON/OFF、**▶ できっかけを待たずに 1 回試す**、**▤ で実行ログ**、✕ で削除。上の「**自動実行を一時停止**」を ON にすると、**どのきっかけが来ても実行しなくなります**（ルールは消えません。▶ で自分から試すことはできます）。下には**直近の発火**が出るので、「さっき何が動いたか」「なぜ動かなかったか（`paused` と出ます）」が分かります。各行の **≡ を掴んで上下にドラッグ**すれば**並べ替え**もできます（0.8.249。並びは記憶されます。**表示順が変わるだけ**で、実行の順番やきっかけには影響しません）。
  端末からも同じことができます: `z2-when pause` / `z2-when resume` / `z2-when fired`。
- **一覧・削除・オンオフ**: `z2-when list`（一覧）/ `z2-when events`（`event:` に使える名前）/ `z2-when remove <id>`（`all` で全部）/ `z2-when on <id>` `z2-when off <id>` / `z2-when log <id>`（実行の記録を見る）
- **実行されるコマンド**の中では `Z2_WHEN_TRIGGER`（発火したトリガー）や `Z2_WHEN_LEVEL`（そのときの電池残量）、`Z2_WHEN_SSID`（wifi 時の接続先）、`Z2_WHEN_NET`・`Z2_WHEN_NET_PREV`（net 時の今/直前の回線）、`Z2_WHEN_SHARE`・`Z2_WHEN_SHARE_KIND`（share 時）、`Z2_WHEN_SMS_FROM`・`Z2_WHEN_SMS_BODY`・`Z2_WHEN_OTP`（sms 時）、`Z2_WHEN_SENSOR`・`Z2_WHEN_LUX`（sensor 時）、`Z2_WHEN_EVENT`（event 時。`alarm` や `notify_action` では `Z2_WHEN_EVENT_NAME`・`Z2_WHEN_ACTION` も）が環境変数で使えます。
- ルールは `~/.z2term/when/` にテキストで置かれるので、**git で同期・バックアップ**できます。
- 時刻は電池にやさしい仕組み（Doze 貫通の AlarmManager）で動くため、**発火が数分ずれることがあります**。`wifi` / `sms` / `sensor` / `cron` の各トリガーはすべて使えます。

### セキュリティ（脆弱性試験）
| コマンド | できること |
|---|---|
| `z2scan self [--save]` | 自端末/localhost の自己診断（公開ポート・sshd 設定・SSH 鍵の権限・world-writable/SUID・PATH）。外部ツール不要。**`--save` を付けると今の結果を「基準」として保存**します |
| `z2scan diff [--quiet]` | もう一度診断して、**基準から変わった所だけ**を出します。`+` が増えたもの、`-` が無くなったもの。**増えたものがあるときだけ終了コード 1**（減っただけなら 0＝わざわざ知らせない）。`--quiet` は変化が無いとき何も出しません |
| `z2scan baseline [clear]` | 保存した基準を表示（`clear` で削除） |
| `z2scan setup` | スキャナ（`nmap`/`lynis`）を distro 公式パッケージで導入 |
| `z2scan net [--allow-remote] [対象]` | `nmap` の TCP スキャン。対象の既定は `127.0.0.1`。localhost 以外は `--allow-remote` 必須＋警告 |
| `z2scan host` | `lynis` でホスト監査（無ければ `self` にフォールバック） |
| `z2scan cve` | `trivy`/`grype` があれば rootfs の既知 CVE をスキャン |

> 注意: 結果はローカル出力のみ（外部送信なし）。**明示的に試験を許可された対象のみ**をスキャンしてください。

**毎日みはる（基準からの変化だけ通知）**

診断の全文を毎日読むのは無理なので、「前と同じ」を基準にして、**増えたものがある日だけ**知らせます。

```sh
z2scan self --save                      # 1 回だけ: 今の状態を基準にする
z2-when time:daily=03:00 run 'out=$(z2scan diff --quiet); [ -n "$out" ] && z2-notify -h "z2scan: 変化あり" "$out"'
```

`--quiet` は変化が無い日は何も出さないので、`[ -n "$out" ]`（中身があるとき）だけ通知が飛びます。
心当たりのある変化（自分でポートを開けた等）なら、`z2scan self --save` で基準を取り直してください。

> 基準は `~/.z2term/scan/baseline.txt` にテキストで置かれます。中身は診断の `[WARN]` / `[INFO]` 行なので、そのまま読めますし、git で持ち歩けます。アプリの表示言語を変えると文字列そのものが変わるため、取り直しが必要です（そのときは警告が出ます）。
