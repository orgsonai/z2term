# エッジパネルの簡易ターミナル

対象: 0.8.620-alpha（versionCode 628）

エッジパネルの「項目追加」で、部品を「入力欄」、動作を「シェルに接続」にします。CLIでは、既存パネルのIDを使って次のように追加します。

```sh
z2-edge set パネルID:terminal type=terminal label=簡易ターミナル
```

最下部の1行入力欄へコマンドを書き、「実行」またはキーボードの実行キーを押します。標準出力と標準エラーは前回の結果に追記します。「コピー」で結果をコピーできます。「停止」はそのセッションと通常のジョブを終了し、結果を残します。**↻（リフレッシュ）**でシェル・結果・入力を手動で初期化し、次の実行で新しいシェルを開始します。停止後も自動では作り直しません。

## 履歴とスニペット

入力欄で **↑** は古い履歴、**↓** は新しい履歴を呼び出し、最後まで戻ると入力途中の文字列へ戻ります。通常の履歴一覧と同じ `~/.bash_history`・`~/.zsh_history` を読み込みます。簡易ターミナル専用の履歴ファイルは作らず、これらのファイルへ直接追記もしません。簡易ターミナルで受け付けたコマンドは、パネルを閉じた後もメモリ上の履歴から呼び戻せます。実行受付後の入力欄は空になり、↑で再入力できます。履歴の選択だけでは実行しません。複数行・16,384文字を超える履歴はこの1行入力では呼び出しません。

操作ボタン列の **≡（スニペット）** で、結果欄の場所に既存のスニペット一覧を開きます。アプリ本体と同じ一覧・並び順・グループ・保存データを使い、別のコマンド登録簿は作りません。タップすると入力欄に入り、**実行**で動かします。「＋新規」で入力中のコマンドを登録でき、一覧の編集・削除も本体へ反映されます。入力補助付きスニペットは値を入力してから挿入でき、ファイル型の値はパスを入力します。複数行のスニペットは通常のターミナルで使ってください。

一覧を閉じると、それまでの結果表示へ戻ります。タブ・入力欄の位置は変えず、操作ボタン用の行も増やしません。

## セッションの範囲

- 項目ごとに同じシェルを使い、`cd`、変数、関数、実行中の処理、出力、入力途中の文字を保持します。
- 閉じる、タブ・パネル・設定への移動、消灯、再読み込み、回転でシェルは終了しません。隠れている間も処理と出力の取り込みを続けます。開き直すと同じ状態に戻ります。
- 入力中の外側タップ・戻るは、まずキーボードと入力フォーカスを解除します。入力していない状態ならパネルを閉じます。**×（閉じる）**は入力中でも使えます。キーボードを隠すだけではパネルを閉じません。外側の長押しは設定を開きます。
- タブがある場合、閉じるボタンはタブ列右端に常設します。タブもパネル名も表示しない場合は操作列に置きます。
- 手動リフレッシュ、停止、項目の削除・別種への変更、パネル機能のOFF、サービス停止・アプリの全停止でシェルを終了します。アプリのプロセス終了後には状態を復元しません。
- 現在選択しているローカルLinux環境を使い、Linux未導入ならAndroid標準シェルを使います。既存の端末タブやSSHのセッションとは共有しません。既存のパネルコマンドと同様、Linuxは実行エンジン経由です。

## 処理の停止

パネルを閉じるだけなら、通常の前景・背景ジョブも継続します。手動リフレッシュ・停止・パネル機能のOFFなどでセッションを終了すると、通常のジョブと、起動元を識別できる分離済み子プロセスを停止します。明示的にハングアップを無視する処理やデタッチされた端末サーバーと配下は従来どおり保持します。Androidによるアプリ停止やプロセス終了をまたいだ継続は保証しません。

## 表示・入力の範囲

表示名を空欄にすると、見出し・内部ID・見出し用の空行は表示しません。ターミナルだけを置いたページは、入力欄を下端に固定して残りの高さを結果へ使います。下部の説明文は常設しません。

結果欄は指で上下にスクロールでき、保持中の結果の末尾まで読めます。結果上の左右フリックはタブ切替、上下ドラッグは結果のスクロールです。上下スクロールを始めた後は左右へ動かしてもタブを切り替えません。長押しは文字選択に使えます。結果はテキスト表示で、直近65,536文字を上限とし、上限を超えた場合はその旨を表示します。表示上限後も出力は読み続けます。ANSIの色・画面制御は表示しません。背景ジョブの出力も到着時点で表示します。

入力は1行、最大16,384文字です。コマンドの標準入力は空として扱うため、対話入力を必要とするプログラムや全画面TUIは通常の端末タブで実行してください。端末を多重化するプログラムは、このパネルではデタッチ状態で起動します。

外部ライブラリ・SDK・モデル・ライセンスファイルの追加はありません。
