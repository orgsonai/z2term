# エッジパネルの簡易ターミナル

対象: 0.8.615-alpha（versionCode 623）

エッジパネルの設定 → **項目 → ＋ターミナル**で追加できます。「項目を追加」の種類で「簡易ターミナル」を選ぶ方法もあります。CLIでは、既存パネルのIDを使って次のように追加します。

```sh
z2-edge set パネルID:terminal type=terminal label=簡易ターミナル
```

最下部の1行入力欄へコマンドを書き、「実行」またはキーボードの実行キーを押します。実行を受け付けると前回の結果を消し、標準出力と標準エラーを逐次表示します。「コピー」で結果をコピー、「消去」で表示だけを消せます。「停止」はそのセッションと通常のジョブを終了し、次の実行は新規セッションになります。

## 履歴とスニペット

入力欄で **↑** は古い履歴、**↓** は新しい履歴を呼び出し、最後まで戻ると入力途中の文字列へ戻ります。通常の履歴一覧と同じ `~/.bash_history`・`~/.zsh_history` を読み込みます。簡易ターミナル専用の履歴ファイルは作らず、これらのファイルへ直接追記もしません。簡易ターミナルで受け付けたコマンドは、開いている間だけ履歴の先頭で呼び戻せます。実行受付後の入力欄は空になり、↑で再入力できます。履歴の選択だけでは実行しません。複数行・16,384文字を超える履歴はこの1行入力では呼び出しません。

操作ボタン列の **≡（スニペット）** で、結果欄の場所に既存のスニペット一覧を開きます。アプリ本体と同じ一覧・並び順・グループ・保存データを使い、別のコマンド登録簿は作りません。タップすると入力欄に入り、**実行**で動かします。「＋新規」で入力中のコマンドを登録でき、一覧の編集・削除も本体へ反映されます。入力補助付きスニペットは値を入力してから挿入でき、ファイル型の値はパスを入力します。複数行のスニペットは通常のターミナルで使ってください。

一覧を閉じると、それまでの結果表示へ戻ります。タブ・入力欄の位置は変えず、操作ボタン用の行も増やしません。

## セッションの範囲

- 開いている間は同じシェルを使います。`cd`、変数、関数などを次のコマンドでも使えます。
- 閉じて開き直すと新しいシェルがホームから始まります。入力・結果・作業ディレクトリ・一時変数は復元しません。コマンドが書き込んだファイルは通常どおり残ります。
- 外側タップ、フォーカス移動、キーボードを隠す操作、「戻る」では閉じません。**×（閉じる）**を使います。タブがある場合はタブ列右端に常設し、タブも閉じるボタンも位置を変えません。タブもパネル名も表示しない場合は操作ボタン列に置き、閉じるだけの行は作りません。外側のタッチはパネルが受け取り、長押しすると設定が開きます。設定へ移ると現在のセッションは終了します。
- 別タブ・別パネル・設定への移動、画面の消灯、パネルの再読み込み・回転による再作成、サービス停止も現在のセッションを終了します。
- 現在選択しているローカルLinux環境を使い、Linux未導入ならAndroid標準シェルを使います。既存の端末タブやSSHのセッションとは共有しません。既存のパネルコマンドと同様、Linuxは実行エンジン経由です。

## 閉じた後も処理を残す

通常の前景・背景ジョブはセッション終了時に停止します。単に末尾へ `&` を付けただけでは残りません。デーモン化してセッションを分離した子プロセスも、起動元を識別できるものは停止対象です。

明示的に残す場合は、それぞれの環境にあるコマンドを使います。

```sh
nohup sh -c 'sleep 600' > "$HOME/edge-job.log" 2>&1 &
tmux new-session -d -s edge-job 'sleep 600'
screen -DmS edge-job sh -c 'sleep 600'
```

`nohup` のようにハングアップを無視する処理と、デタッチした `tmux` / `screen` およびその配下は保持します。通常の端末から各コマンドの管理・停止操作を行えます。これらはアプリのプロセス終了やAndroidによる停止まで生存を保証するものではありません。

## 表示・入力の範囲

表示名を空欄にすると、見出し・内部ID・見出し用の空行は表示しません。ターミナルだけを置いたページは、入力欄を下端に固定して残りの高さを結果へ使います。下部の説明文は常設しません。

結果欄は指で上下にスクロールでき、保持中の結果の末尾まで読めます。結果上の左右フリックはタブ切替、上下ドラッグは結果のスクロールです。上下スクロールを始めた後は左右へ動かしてもタブを切り替えません。長押しは文字選択に使えます。結果はテキスト表示で、直近65,536文字を上限とし、上限を超えた場合はその旨を表示します。表示上限後も出力は読み続けます。ANSIの色・画面制御は表示しません。背景ジョブの出力も到着時点で表示します。

入力は1行、最大16,384文字です。コマンドの標準入力は空として扱うため、対話入力を必要とするプログラムや全画面TUIは通常の端末タブで実行してください。`tmux` / `screen` は、このパネルではデタッチ状態で起動する用途に使います。

外部ライブラリ・SDK・モデル・ライセンスファイルの追加はありません。
