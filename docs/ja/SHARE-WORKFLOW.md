# ファイル共有・まとめて受取・コマンドの入力補助

対象: 0.8.611-alpha（versionCode 619）

## ファイルを他のアプリへ送る

ローカルの端末タブから実行します。

```sh
z2-share --file /sdcard/Download/report.pdf
z2-share --file /sdcard/Download/photo.png /sdcard/Download/report.pdf
```

Androidの共有先一覧が開きます。送り先を選ぶと、パスの文字列ではなくファイル本体を渡します。今のシェルで読める通常ファイルを1〜32件、合計512MiBまで指定できます。フォルダーは事前にアーカイブにしてください。SSH先のファイルは、先に端末へ転送してください。

アプリ専用キャッシュへコピーして渡すので、共有先が読んでいる途中に元ファイルを変更しても内容は変わりません。共有先への権限は読取専用です。24時間を過ぎた送信用コピーは次回共有時に掃除します。Androidによるキャッシュ削除もあるため、送り先では必要に応じて保存してください。コマンドの成功は共有先一覧を開いたことを表し、送り先での送信完了を表しません。

文字だけの共有は `z2-share "文字列"`。オプションと同じ文字を共有する場合は `z2-share -- "--file"` を使います。

## 本文と添付をまとめて受け取る

相手のアプリの「共有」で通常の **z2term** を選びます。本文・件名・添付を、受取ごとの `~/z2term-inbox/受取ID/` へまとめて保存します。本文中のURLもそのまま残します。相手が渡していない本文や送信元情報を補完する機能ではありません。

添付は最大32件、各512MiBです。1件でも読めない場合は今回の取込全体を失敗にし、途中のコピーを残しません。取込済みのファイルは自動削除しません。

- 処理の登録がなければ、本文がある場合は本文、ファイルだけなら引用符付きのパスを入力行へ入れます。本文と添付が両方ある場合も添付は保存済みです。
- 処理を登録してあれば、本文・添付名と処理一覧を表示します。処理を選ぶ、元の内容を挿入する、保存したまま閉じる、から選べます。
- 挿入後は内容を確かめてEnterで実行します。共有を受けただけでは、選択したコマンドを実行しません。既存の `z2-when share:` ルールを登録している場合、その自動処理は従来どおり動きます。

### 受取時の処理を登録する

1. コマンド一覧 → **スニペット** → 新規または編集を開きます。
2. 名前とコマンドを入力し、**「共有を受け取ったときの選択肢に出す」**をONにして保存します。
3. 他のアプリから共有すると、その名前を処理一覧から選べます。

処理の例:

```sh
cat "$Z2_SHARE_MANIFEST"
```

選んだコマンドには `Z2_SHARE_TEXT`（元の本文）と `Z2_SHARE_MANIFEST`（受取情報JSONの絶対パス）が渡ります。本文やファイル名はシェルのコードとして組み立てず、データとして渡します。JSONは以下の形です。

```json
{
  "version": 1,
  "id": "受取ID",
  "receivedAt": 1789488000000,
  "text": "共有された本文とURL",
  "subject": "件名",
  "files": [
    { "name": "report.pdf", "path": "z2term-inbox/受取ID/report.pdf", "size": 1234 }
  ]
}
```

`receivedAt` はUnix時刻のミリ秒、`files[].path` は共有ホームからの相対パスです。実ファイルを開く際は `$HOME` に続けてください。受取と入力補助のファイルは端末ローカルに置かれ、SSH先へは自動転送しません。

自動化の `share:` には `Z2_WHEN_SHARE_MANIFEST`（ホームからの相対パス）と `Z2_WHEN_SHARE_TEXT`（本文）を追加しました。本文と添付が両方あると `Z2_WHEN_SHARE_KIND=mixed` になり、`share:text` と `share:file` の双方の条件に合います。`share:any` のルールは1受取につき1回です。

## スニペットの引数を入力欄で指定する

スニペットの編集で **「挿入前に入力欄を出す」**をONにします。コマンドに次の書式を入れると、項目ごとの入力欄が出ます。

| 書式 | 入力欄 |
|---|---|
| `{{名前}}` / `{{名前:text=初期値}}` | 文字列 |
| `{{回数:number=3}}` | 数値 |
| `{{形式:choice=png\|jpg}}` | 選択肢 |
| `{{ファイル:file}}` | パス入力とファイル選択 |

たとえば `wc -l {{ファイル:file}}` を保存すると、押した時にファイルを指定してからコマンドを挿入できます。ファイル選択で取り込んだ実体は共有ホームに保存します。受取時の処理として使う場合、添付が1件なら自動で入り、複数なら選べます。

項目は最大16個です。同じ定義を繰り返すと1つの入力を共用します。`{{...}}` は引用符の外で、空白などで区切った1引数として置いてください。`"{{名前}}"` や `--name={{名前}}` は使わず、`--name {{名前}}` の形にします。

入力した値を位置引数として渡す `sh -c` のコマンドをプレビューします。引用符・改行・`$(...)` を入力しても、それだけで別のコマンドにはなりません。値は登録したコマンドの引数になります。入力補助がOFFの既存スニペットは、`{{...}}` を含めて従来どおりそのまま挿入します。
