## z2term 0.8.190-alpha (versionCode 198)

SMS の確認コード（ワンタイムパスワード）を自動で拾えるようにしたリリース。
あわせて、マクロ導入コマンドが動かなかった不具合と、一部の端末にインストールできない
問題を直しました。full 版も Release に添付するようになりました。

## 主な変更点（v0.8.184 以降）

### SMS の確認コードを自動で取得（0.8.186）
- 通知を読む方式では、Android 15 以降の「機微な通知の保護」により本文が
  **伏せ字に置き換えられてから**アプリへ渡されます。通知アクセスを全許可しても外せず、
  確認コードは原理的に取得できませんでした。
- SMS そのものを直接読む方式に変更しました。伏せ字も画面ロックも通りません。
- 設定の「SMS 検知」を ON にして SMS の受信許可を与えると、受信内容が
  `~/.z2term/sms.jsonl` に追記されます（送信元・本文・時刻）。
- アプリを起動していなくても、画面がロックされていても受信できます。常駐サービスは不要です。
- **既定は OFF**、明示的な許可制、記録は端末内のみで外部送信はありません。
- `z2-macro install otp-sms.sh` でサンプルが入ります。確認コードだけをクリップボードへコピーし、
  一定時間後に自動で消す動作をそのまま使えます。

### 通知から本文を読める範囲を拡大（0.8.185）
- 従来は本文が空に見える通知がありました。メッセージ形式・受信箱形式の通知は本文が
  別の場所に入っているためです。
- 表示に使われている文字を順に探すようにし、これらの通知でも本文を拾えるようにしました。
- ただし前述のとおり、Android 15 以降で保護対象と判定された通知の本文は伏せ字のままです。

### マクロ導入コマンドが起動できなかったのを修正（0.8.187）
- `z2-macro` がどのサブコマンドでも構文エラーで止まり、**同梱サンプルを一度も導入できない**
  状態が続いていました。生成されるスクリプトの一部に余分な記号が残っていたためです。
- 修正し、同じ壊れ方をしないことを自動テストで固定しました。

### タブレットなどにインストールできなかったのを修正（0.8.188）
- SMS の受信許可を宣言したことで、Android が「電話機能が必須のアプリ」と解釈し、
  タブレットや ChromeOS からインストールできなくなっていました。
- 電話機能は必須ではないと明示し、従来どおりインストールできるようにしました
  （その端末では SMS 検知が動かないだけです）。

### 表示と動作の修正（0.8.189 / 0.8.190）
- 数を伴う表示（「コピー (N 文字)」「↑N行」「N 件の単語を学習済み」など）を複数形に対応。
  英語表示での単複の不整合が解消されます。
- 端末の色問い合わせへの応答が、数字の字形が ASCII でない環境で壊れうるのを修正。
- 画面のレイアウトのたびにメモリを確保していたのをやめ、キーボード開閉やリサイズ時の負荷を軽減。
- SFTP の日時表示が、アプリ内の言語切り替えに追従しなかったのを修正。
- GUI 操作でのタップがアクセシビリティサービスへ通知されていなかったのを修正。

### full 版も自動で配布（0.8.190）
- これまで自動で添付されていたのは foss 版のみで、full 版は手動配布でした。
  今回から**両方が Release に添付**されます。
- あわせて、公開前に「署名が正しいこと」「foss 版に余計な同梱物が入っていないこと」を
  検査するようにしました。
