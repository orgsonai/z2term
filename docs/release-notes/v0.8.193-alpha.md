## z2term 0.8.193-alpha (versionCode 201)

検索バーとスクロールバーを「指で普通に操作できる」ところまで直したリリース。
あわせて ⏎ の長押し連打と ALT+矢印の取りこぼしを修正しました。

## 主な変更点（v0.8.190 以降）

### 検索バーに文字カーソルが出て、途中から打ち直せる
- 内蔵キーボードで検索するとき、これまでは**カーソル（キャレット）が一切表示されず**、
  末尾に足すか末尾から消すかしかできませんでした。
- カーソルを自前で描くようにして、**タップした位置にカーソルが移動**し、語の途中の
  打ち直しができるようになりました。
- ← → でカーソル移動（↑ で先頭、↓ で末尾）、BS はカーソルの直前を 1 文字削除。
- 語が枠より長くなったら、カーソルが見える位置まで自動で横スクロールします。
- システムキーボードを使っている場合の動作は従来どおりです。
- 途中で入っていた「検索バーに文字を打つとアプリが落ちる」「打つとカーソルが消える」も
  同じ範囲で修正済みです。

### スクロールバーが触れた瞬間から動く
- つまみを掴んでから動き出すまでのラグと、**掴んでも 1px も動かない**症状を直しました。
  指が触れた瞬間から追従し、画面に文字が流れている最中でも掴んだ指が外れません。
- 当たり判定を広げ（横 32dp・上下にも余裕）、掴んでいる間はつまみの色が濃くなります。

### 他アプリでコピーした内容がクリップボード履歴に入らない
- Android 10 以降はアプリが前面にある間しかクリップボードを読めません。復帰の判定が
  早すぎて空のまま取り込む端末があったため、**ウィンドウが実際に前面になった時点**でも
  取り込むようにしました。

### ⏎ の長押しで連打できる
- 矢印キーや space と同じように、**⏎ を押しっぱなしにすると連続して改行**を送ります
  （長押し 400ms から 55ms 間隔）。英字レイアウト・かなフリック・システムキーボード時の
  特殊キーバー、いずれでも同じように効きます。

### ALT / META + 矢印が効かなかったのを修正
- ALT や META を押しながら矢印を押しても**修飾が捨てられ、ただの矢印**になっていました。
  文字キーでは効いていたので、矢印だけの取りこぼしです。
- 修正により、readline を使うシェルで ALT+b / ALT+f（単語単位の移動）と同じ感覚で
  ALT+← / ALT+→ が使えます。

### 同梱物ビルド用スクリプトの修正（開発者向け）
- root で実行すると deb の展開でエラー終了する問題、回線が遅いと最新版の検出に失敗して
  止まる問題、完了点検が配置先を間違えて必ず MISS を出す問題を修正しました。
- アプリの動作そのものには影響しません。
