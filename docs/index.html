What it does

Everything below is in the one APK. No companion app, no setup script, nothing to wire together first.

01A distribution, immediately

Install the APK and apk / apt / pacman work. The default engine z2root is a ptrace-based userspace implementation written for this app — no root, no kernel module. Pick Alpine, Ubuntu, Arch or Kali in Settings.

02The shell reaches the phone

Around 20 z2-* helpers: notifications, toasts, clipboard, sensors, torch, volume, intents, alarms, text-to-speech, screen-on, share, and wireless adb to the device itself. Every one of them is a normal command, so anything that can call a command can use them.

03It can ask you things

name=$(z2-ask "Branch name?") puts the question in the notification shade and reads your reply back into a shell variable. Answer it without opening the app; no answer is a non-zero exit, so "give up" is expressible too.

04Automation that outlives the app

z2-when runs scripts on device events — charging, battery level, time or cron, Wi-Fi, connectivity, boot, a share from another app, an incoming SMS, sensors, an arriving notification, a new file. Rules are plain text and fire with the app closed, across reboots.

05A Linux desktop in a tab

Xvnc and openbox with an RFB client built into the app, with audio and video. z2gui starts the desktop; z2run <app> launches a GUI program and opens the tab for you.

06Someone else's desktop, too

The same viewer opens a remote VNC or RDP machine: a saved host gets [VNC] and [RDP] buttons. RDP does Network Level Authentication with a first-use certificate check, mouse and keyboard, sound, and shared text clipboard.

07Files, four ways

SSH / SFTP, FTP, WebDAV and SMB2/3 clients. Each service rides a temporary SSH forward by default, so the credentials never cross the network in the clear. Keys are ed25519 held by the Android Keystore, and -L / -R forwards keep running after the tab closes.

08Servers that stay up

Register a start command under Settings → Resident servers and it keeps running in the background — without the app being open, and again after a reboot. Host a small web server, a sync daemon or a bot from the phone.

09Within reach, without the app

Put a macro on a quick-settings tile (12 slots), draw its status-bar icon yourself, or run it from a home-screen widget with one tap. A second widget keeps the tail of any file under ~ on your home screen.

10USB devices from ordinary programs

z2-usb list, then z2-usb allow and approve Android's permission — after that, programs using libusb or /dev/bus/usb/… open the device without being patched. A plain data-capable adapter or hub is all the hardware it takes.

11When it doesn't work

z2doctor answers "why isn't it working?" in one command — version, engine, free space, every permission, detection and automation state. Each NG line carries the next step, and the end is a report you can paste into an issue.

A macro is just a command — so it can be anything

There is no macro language to learn. A macro is a shell script that happens to be able to touch the phone: post a notification, raise a toast, ask you something, flick the torch, put itself on a tile. Whatever you can write, the phone can do — and z2-when can fire it while the app is closed. Watch the phone on the right.

A desktop in a tab — yours or a remote one

The GUI tab is not a separate viewer app. It is an RFB client inside z2term, so a Linux desktop and a remote machine both land in the same tab strip as your shells.

localXvnc + openbox

z2gui brings up the desktop; z2run <app> starts a GUI program and opens the tab for you. Audio and video are bridged, so a media player is a media player.

vncAny RFB server

RFB 3.3 – 3.8, None or VNC-password authentication. Save a host once and it gets a [VNC] button next to it.

rdpWindows, properly

Network Level Authentication, a certificate check on first use, mouse and keyboard input, sound, and text clipboard sharing both ways. Saved hosts get an [RDP] button.

sshTunnelled by default

A remote desktop, like FTP, SMB and WebDAV, rides a temporary SSH local forward unless you explicitly opt out — and opting out warns you that the encryption goes with it.

The rest of it, in one screen

terminal
VT100 / xterm, 256-color and true color, 9 themes, scrollback with search, UTF-8 and East Asian Width, alternate screen, OSC 4 / 7 / 8 / 10 / 11 / 12 / 52.
engine
z2root — a ptrace-based userspace implementation written for this app. No root, no kernel module. Rooted devices may optionally use a chroot path.
tabs
CUI and GUI tabs, drag to reorder. An inactive tab shows a dot while something runs in it, and a ✓ when it finished while you were looking elsewhere.
ssh
Client and a built-in sshd (localhost-only by default). ed25519 keys created in the app, secrets encrypted by the Android Keystore, known_hosts confirmation, and forwards that outlive the tab.
languages
English, Japanese, Simplified and Traditional Chinese — the in-app UI and the z2-* help text, usage lines and messages you get in the terminal.
security
App lock by fingerprint, face or screen lock, with the recent-apps thumbnail hidden while you are away — sessions and resident servers keep running. z2scan self audits this device with no external tools; results stay local.
data limit
Once the whole phone's mobile usage for the period reaches the amount you set, z2term's own traffic stops. Wi-Fi and your home network keep working; other apps are untouched.
backup
Settings, connections, snippets, automation rules, macros, theme, tiles, icons, dictionaries and what the keyboard learned — one file, restorable on another device, optionally on a schedule. SSH secrets are left out unless you give a passphrase, which also encrypts the rest.
terminal log
Tap ⚪ to start writing what the tab shows to a text file in ~/z2term-log/; tap again to stop. Colors and control codes are stripped by default.
share & snippets
Text shared from another app is inserted on the input line, never executed. Snippets sort onto shelves so the ones you use don't sink out of reach.
licence
GPL-3.0. No telemetry, no account, no in-app purchase, not on Google Play.

Keeping it updated

in-appCheck for updates

Settings → App info → Check for updates. It asks GitHub only when you tap the button, downloads the new APK and takes you to the install screen — the last tap is always yours, because no app can replace itself silently. From the shell: z2-update.

autoObtainium

Add github.com/orgsonai/z2term to Obtainium and it watches Releases, updating with one tap when a new version appears. No store involved.

manualTap the APK

Download the newer file from Releases and tap it. It installs over the top and your data stays where it is.

Still versioned 0.8.x-alpha: the feature set is wide and in daily use, but the version number is honest about it.
