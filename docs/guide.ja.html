使いこなしガイド

Z2Term は「Android で動く Linux ターミナル」であると同時に、 シェルから Android そのものを操作する道具です。後半がまるごと独自のしくみなので、 Linux に慣れている方でも、知らなければ使えません。 このガイドは、その独自部分を順番に説明します。

はじめての方は 下の「最初の 15 分」だけ読めば、ふつうのターミナルとして使えます。 その先の 4 章が、このアプリならではの部分です。

このアプリで何ができるか

できることひとことで言うと詳しく
Linux を動かす root 不要で Alpine / Ubuntu / Arch / Kali。apk apt pacman がそのまま使えます 1. ターミナル
Android を操作する 通知を出す・質問する・クリップボード・ライト・音量・センサー・SMS を シェルから 2. マクロ
ひとりでに動かす 充電・時刻・Wi-Fi・共有・着信などをきっかけに、アプリを閉じていてもスクリプトが走ります 3. 自動化
すぐ手が届く場所に置く クイック設定のタイル・ホーム画面のウィジェットから、アプリを開かずに実行 4. タイルとウィジェット

最初の 15 分

  1. APK を入れて開く。 GitHub Releases から z2term-<版数>.apk（約 21MB）を入れてください。APK はこの 1 つだけです。 初回起動で 設定 › Linux 環境からディストロを選ぶと、それが取得されて Linux が立ち上がります。
    OS も外部の prebuilt も同梱していないので 初回だけネット接続が必要です。 取得元は公式 CDN で、SHA-256 で検証されます。取得は 1 回きりで、アプリを更新しても落とし直しません。
  2. 画面の見かたを覚える。上のバーがツールバー、その下がタブ、真ん中が端末、下がキーボードです。 ボタンは長押しで並べ替えられ、使わないものは設定で消せます。 → 1. ターミナル
  3. 日本語を打ってみる。キーボード左の「あ」で日本語フリックに切り替わります。 変換は候補バーから。OS のキーボードとしても使えます（設定 → キーボード）。
  4. ディストロは後から変えられる。⚙ 設定 →「Linux 環境」で Alpine / Ubuntu / Arch / Kali。 迷ったら Alpine のままで構いません。
    claude や gcc など glibc 前提のものを動かすなら Arch を選んでください。 Alpine（musl）では起動できないものがあります。
  5. 同梱のマクロを入れてみる。端末で z2-macro install all と打つと、 すぐ使えるサンプルが ~/.z2term/macros/ に入ります。ここが 2 章以降の出発点です。

4 つの章

1ターミナルとして使う

画面の見かた、ツールバーの各ボタン、独自キーボードとフリック、コピーと検索、 パッケージの入れかた、PC からの SSH、ファイルのやりとり。

2マクロ（Android を操る）

z2-* コマンド一覧と、その組み合わせ方。通知を出す、通知で質問して答えを受け取る、 同梱サンプルの使いかた、自分のマクロの書きかた。

3自動化（z2-when）

きっかけの一覧と条件の絞り込み。充電・時刻・Wi-Fi・共有・SMS・通知・センサー・ファイル。 動かないときの調べかたまで。

4タイル・ウィジェット・アイコン

クイック設定に置く、ホーム画面に置く、常駐サーバー、通知とタイルのアイコンを 自分のドット絵にする。

困ったときは

  • まず z2doctor。環境の状態をまとめて出します（z2doctor --clip で結果をコピー）。
  • コマンドの使い方は z2help。個々のコマンドは --help を付けると詳しい説明が出ます （例: z2-when --help、z2-icon --help）。
  • より細かい仕様は ハンドブックと マクロガイドにあります。
  • うまくいかない・分かりにくいところは Issues へどうぞ。
