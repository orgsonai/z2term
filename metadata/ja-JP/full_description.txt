Z2Term (ズィートゥーターム) は、Android のターミナルであり、Android を操作する手段でもあるアプリです。

Alpine / Ubuntu / Arch / Kali を root 不要で動かし、タブの中に Linux のデスクトップを開き、シェルから端末そのものに手を伸ばせます。通知を読む、通知シェードの返信欄であなたに質問する、充電・ネットワーク・受信 SMS の変化でスクリプトを走らせる、といったことができます。

* root 不要の Linux ディストロ: z2root は本アプリ用に書いた ptrace ベースのユーザ空間実装で、ソースからビルドされます。root端末では実chrootも任意で利用できます。
* ターミナルエミュレータ: VT100 / xterm、256 色・トゥルーカラー、代替スクリーン、East Asian Width (CJK・絵文字を 2 セル幅で描画)、OSC 4/7/8/10/11/12/52
* 9 種類の同梱テーマ + 独自テーマの作成 + カスタムフォント
* 5,000 行のスクロールバック (500〜50,000 で変更可) と検索
* マルチタブ (タブごとに独立したエミュレータ、ドラッグで並べ替え)
* Linux GUI: Xvnc + openbox をアプリ内蔵の RFB クライアントで表示。音声・動画つき。「z2gui」でデスクトップ、「z2run <アプリ>」で GUI アプリを起動。同じ画面から別のパソコンへ VNC / RDP でも繋げます
* SSH / SFTP クライアント (公開鍵認証・秘匿情報は Android Keystore で暗号化)、タブを閉じても生き続ける双方向ポート転送、既定で localhost のみに bind する内蔵 sshd
* Android ブリッジ: 約 40 個の「z2-*」コマンドでシェルから本体機能を呼ぶ (通知・クリップボード・電池・センサー・ライト・Intent・アラーム・読み上げ、自端末への無線 adb)
* 人に聞ける:「z2-ask」は通知シェードに質問を出し、返信をシェル変数として受け取ります
* 自動化ハブ:「z2-when」が端末のイベントでスクリプトを起動 (充電・電池残量・時刻や cron・Wi-Fi・回線・起動・他アプリからの共有・SMS 受信・センサー・通知の着信・ファイルの追加)。条件で絞り込め、ルールはテキストファイルで、アプリを開かなくても再起動をまたいで働きます
* 常駐サーバー: 任意の起動コマンドを登録すると、アプリを開かなくてもバックグラウンドで動き続けます
* エッジパネル: 他のアプリの上に浮かべて使う板。ボタン・メモ・小さな端末・自作マクロを並べ、画面の端のバーを払うと開きます
* 操作自動化: 画面のタップ・スワイプ・ジェスチャーを記録して再生します。繰り返し・条件分岐・他のマクロ呼び出しを組み合わせられ、タイル・ウィジェット・エッジパネルから実行できます
* QR ツール: オフラインで QR を読み取り・作成し、履歴に残します。端末からは「z2-qr」でも作れます
* 撮りたいところだけ撮る: 「z2-shot」で画面を取り、残す範囲を指でなぞって囲み、保存・共有できます
* 端末で作った頁を読む: 「z2-view」はアプリの中で表示します (JavaScript も外部通信も切った状態)
* 日本語 IME: かな漢字変換・予測・学習と独自オンスクリーンキーボード。OS の入力メソッドとしても有効化でき、他アプリでも同じ変換が使えます。キー配列はかな・英字・記号のどの面でも編集でき、名前を付けて保存・切り替えできます。ユーザー辞書はファイル (SKK 形式) から読み込めます
* 端末ログ: そのタブの表示内容をワンタップでテキストファイルに記録
* ホーム画面ウィジェット: 状態表示とマクロのランチャー、任意ファイルのライブ tail
* 共有シートからの受け取り: 他アプリのテキストやファイルを入力行に「入れるだけ」(実行はしません)
* 持ち出し: 設定・SSH 接続先・スニペット・自動化ルール・マクロを 1 ファイルにまとめて別端末へ
* 内蔵ヘルプ「z2help」と自己診断「z2doctor」(「動きません」に対し、NG の行ごとに次の一手を示します)
* フォアグラウンドサービスでセッションを維持、物理キーボード対応、長押し範囲選択とコピー / 貼り付け、ピンチでフォントサイズ変更

完全ローカルで、テレメトリも解析もありません。このビルドは第三者の prebuilt を一切同梱せず、Linux ディストロは初回起動時に公式 CDN から取得して SHA-256 で検証します。それ以外はオフラインで動きます。
