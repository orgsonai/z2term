Z2Term is a self-contained terminal emulator for Android with:

* PRoot-based Linux: run Alpine or Ubuntu without root
* Full VT100/xterm escape sequence support (colors, attributes, alt screen)
* 6 built-in themes (ZTS, Solarized, Dracula, Gruvbox, Nord, Tokyo Night)
* Custom font loading from assets/fonts
* East Asian Width (CJK / emoji) rendered as 2 cells
* 5,000-line scrollback (configurable 500–50,000)
* Multi-tab sessions with independent emulators
* Foreground service keeps your session alive across Activity recycles
* Physical keyboard support (Bluetooth keyboards, Chromebook, etc.)
* Long-press range selection + clipboard copy/paste
* SSH client built in (JSch, password auth)
* IME-aware realtime input mode for CJK languages
* Pinch-to-zoom font size

100% local — no telemetry, no analytics, no required network.
